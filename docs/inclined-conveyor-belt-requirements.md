倾斜带从底端（左下）升到顶端（右上）；上表面向上行 → 滚筒顺时针旋转，向下行 → 逆时针旋转。

| 情景 | 用户描述 | 带的运行 | 页面参数 |

| 情况二 | 小木块在下方放置，顺时针旋转 | 带**向上**运行 | 初始位置=底端、v<sub>带</sub>=+2 m/s、v₀=0（轻放） |

| 情景 | θ | μ | v<sub>带</sub> | v₀ | 初始位置 | 演示主线 |
|---|---|---|---|---|---|---|
| 情况一：顶端轻放 · 带向下（逆时针） | 30° | 0.65 | −2 m/s | 0 | 顶端 | 物块相对带向上滑 → 摩擦沿带向下，a₁ = g·sinθ + μg·cosθ ≈ 10.6 m/s² 快速加速 → 共速后随带匀速下行（μ > tanθ，静摩擦维持）→ 滑出底端 |

### 3.2 推导与判断按情景动态化

随参数实时更新（同摩擦转化页方式），五行结构：

1. **受力行**：N = mg·cosθ（数值）；滑动摩擦 f = μmg·cosθ（数值）及方向（由相对滑动方向判断：情况一物块相对带向上滑 → f 沿带向下；情况二相对下滑 → f 沿带向上）
2. **阶段行**：当前阶段加速度表达式与数值——情况一 a₁ = g·sinθ + μg·cosθ；情况二 a₁ = μg·cosθ − g·sinθ
3. **共速行**：共速时刻 t₁ = |v<sub>带</sub>|/|a₁| 与共速位置数值
4. **分支行**：μ 与 tanθ 实时比较 → 共速后"静摩擦维持匀速"（μ ≥ tanθ）还是"继续加速 / 无法上带"（μ < tanθ）
5. **滑出行**：预计从哪端滑出（顶端/底端/无法上带）

子分支说明（通过调小 μ 实时观察，推导行同步切换结论）：
- 情况一 μ < tanθ：共速后静摩擦不足，以 a₂ = g·sinθ − μg·cosθ 继续加速下行
- 情况二 μ ≤ tanθ：a₁ ≤ 0，物块无法上带，沿带下滑滑出底端

### 3.3 画布旋转方向标注

- 顶端滚筒旁绘制弧形箭头 + "顺时针 / 逆时针"文字（随 v<sub>带</sub> 方向切换；v<sub>带</sub> = 0 时不标注）

6. 旋转方向标注随 v<sub>带</sub> 正负切换，v<sub>带</sub>=0 时消失
