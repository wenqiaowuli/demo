# 加速度与力、质量的关系演示网页

## 1. 模型卡与教材对应

- **清单编号**：必修第一册 #21（控制变量实验）
- **页面 slug**：`acceleration-force-mass`
- **文件名**：`acceleration-force-mass.html`
- **所属内容**：必修第一册第四章“运动和力的关系”——牛顿运动定律
- **查重结论**：现有 `horizontal-linear-motion.html` 演示匀变速直线运动和 v-t/s-t 图，但不是控制变量实验；`inclined-plane-block.html`、传送带等页面会使用 F=ma，却不是本模型。仓库中没有固定质量改变合力、固定合力改变质量并比较加速度的专页。
- **页面目标**：用两组理想化实验呈现合力与加速度的正比关系、质量与加速度的反比关系，并统一到 `a=F/m`。
- **与 #22 的边界**：本页负责“控制变量验证 a 与 F、m 的关系”；不扩展为任意方向、多个力分解或多物体的牛顿第二定律综合应用。
- **非目标**：不加入摩擦、斜面、碰撞、变力、弹簧或滑轮；不把质量影响说成物体“运动快慢”的直接决定因素，明确由合力和质量共同决定加速度。

## 2. 冻结的物理规格

- 研究对象：质量为 `m` 的单个物块置于水平光滑面上，合外力 `F` 水平向右；物块从静止开始，参考系相对地面静止。
- 水平运动：`a=F/m`、`v(t)=at`、`s(t)=½at²`。竖直方向支持力与重力平衡，不参与本页主要探究。
- **实验一：研究 a 与 F 的关系**：保持质量 `m` 不变，改变合力 `F`，比较各组加速度；`a/F=1/m`（F>0），`a-F` 图像是过原点直线。
- **实验二：研究 a 与 m 的关系**：保持合力 `F` 不变，改变质量 `m`，比较各组加速度；`am=F`，`a-m` 图像为反比例曲线。
- 控件当前值代表本轮实验中的固定条件与当前测量条件；切换实验模式保留参数数值，但明确更新“保持不变”的变量标签及数据点。
- 边界：`F=0` 时 `a=0`、`v=0`、`s=0`；`m` 必须大于零。页面不允许负质量或负合力。

## 3. 页面需求与交互

- 页面延续浅色主题、单列布局、最大宽约 880px；Canvas 按容器宽度和 DPR 自适应。
- 场景展示光滑水平面、物块、合力 F 与加速度 a 的方向矢量；镜头跟随运动，不显示虚构边界或碰撞。
- 模式切换：“固定质量，改变合力” / “固定合力，改变质量”。两种模式均显示 m、F 控件，但突出本实验的保持量及被改变量。
- 参数范围：`m=0.5–10 kg`，步长 `0.5 kg`，默认 `2 kg`；`F=0–20 N`，步长 `0.5 N`，默认 `4 N`。滑条与数字输入同步；播放中锁定参数，暂停/结束后改参回到 `t=0` 重算。
- 播放：开始、暂停/继续、单步、重置、倍速、进度条；总时长固定 6 s，结束显示“演示结束”。
- 实时量：`t,m,F,a,v,s`，关系式显示 `F=ma`，单位同步。
- 实验图表：模式一显示 `a-F` 直线；模式二默认显示 `a-m` 反比例曲线，并可切换为 `a-1/m` 直线以线性化验证。突出当前点，并列出代表性实验组数据及保持不变的变量；图线和数据必须依据同一物理内核计算。
- 场景分别标出 F 与 a，颜色/位置区分，并明确“加速度 a 不是力”；F=0 时两个水平矢量均不绘制。
- 切换实验模式时保留 m、F 当前数值、回到 `t=0` 并重建图表/数据；每一模式清楚显示控制变量状态。
- 窄屏下场景、图表和数据卡可读，图表纵向排列；可访问名称覆盖滑条、按钮和模式切换。

## 4. 验收矩阵

| 用例 | 参数/操作 | 预期结果 |
|---|---|---|
| 默认值 | `m=2 kg,F=4 N` | `a=2 m/s²`；显示 `F=ma` |
| 固定质量实验 | `m=2 kg`，取 `F=0,4,8,12,20 N` | `a=0,2,4,6,10 m/s²`；a-F 图为过原点直线 |
| 固定合力实验 | `F=4 N`，取 `m=0.5,1,2,4,8,10 kg` | `a=8,4,2,1,0.5,0.4 m/s²`；a-m 图为反比例曲线 |
| 反比线性化 | 固定 `F=4 N`，显示 `a-1/m` | 过原点直线，斜率为 `F`；横轴单位 `kg⁻¹` |
| 质量影响 | 固定 F 增大 m | a 减小，且 `am=F` 恒定 |
| 合力影响 | 固定 m 增大 F | a 同比例增大，且 `a/F=1/m`（F>0） |
| 零合力 | `F=0` | a、v、s 为零；物块静止；a-F 和 a-m 图与当前模式一致 |
| 参数边界 | m 最小/最大、F=0/最大 | 无 NaN/Infinity、除零或不合法参数 |
| 运动关系 | 任意 t | `v=at`、`s=½at²`；位移、动画和实时读数一致 |
| 播放控制 | 播放、暂停、继续、单步、进度、结束、重置 | 状态与读数同步；播放中物理参数禁用 |
| 响应式 | 桌面、800px、390px 左右 | 无水平溢出；场景、图表和控件可读 |
