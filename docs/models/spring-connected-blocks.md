# 弹簧连接物块动画网页

## 1. 模型卡与教材对应

- **清单编号**：必修第一册 #27，第四章“运动和力的关系”中的拓展模型。
- **页面 slug / 文件名**：`spring-connected-blocks` / `spring-connected-blocks.html`。
- **页面目标**：用水平光滑面上由轻弹簧连接的 A、B 两物块，展示恒力作用于 B 时的弹力反馈、两物块加速度差异和质心整体加速。
- **查重结论**：本地及远程 `origin/main` 导航中均无此模型页面。远程导航已读取；直接请求 `https://raw.githubusercontent.com/wenqiaowuli/demo/main/spring-connected-blocks.html` 返回 HTTP 404。`spring-vs-rope-demo.html` 展示弹簧/绳子悬球被剪断后的下落对比；`light-rope-connected-bodies.html` 展示轻绳约束下的共同加速度；两者均不覆盖本页的弹性连接和可变弹力。远程 `index.html` 与本地导航均未登记此模型。
- **范围确认**：采用“水平光滑面、两物块、弹簧、对 B 施加向右恒力、由静止开始”的单一模型。用解析解呈现理想弹簧振动，作为牛顿第二定律应用的拓展；不声称该简谐运动内容属于第四章正文。
- **非目标**：不模拟阻尼、摩擦、外力撤去、竖直弹簧、碰撞、弹簧质量、非线性弹簧和初始相对速度。

## 2. 冻结的物理规格

### 2.1 对象、假设与约定

- A、B 质量分别为 `mA`、`mB`，在水平光滑面运动；轻弹簧原长 `L0 = 2.2 m`、劲度系数 `k > 0`，弹簧始终处于线性弹性范围。
- 忽略空气阻力、摩擦和弹簧质量；恒力 `F ≥ 0` 水平向右作用于 B。取向右为正。
- 弹簧形变量 `e = xB - xA - L0`，伸长为正、压缩为负。初始速度 `vA(0)=vB(0)=0`，初始形变量为 `e0`。
- 参数范围：`mA,mB ∈ [0.5,4] kg`，`k ∈ [5,50] N/m`，`F ∈ [0,12] N`，`e0 ∈ [-0.5,0.5] m`。故弹簧长度始终大于 `1.7 m`，模型无几何穿越。

### 2.2 受力方程和解析状态

- 弹簧对 A 的力为 `+ke`，对 B 的力为 `−ke`；B 另受外力 `+F`。
- `mA aA = ke`；`mB aB = F − ke`。
- 总质量 `M=mA+mB`，约化质量 `μ=mA mB/M`，相对角频率 `ω=√(k/μ)=√[k(1/mA+1/mB)]`。
- 质心：`aCM=F/M`，`vCM=Ft/M`，`xCM−xCM(0)=Ft²/(2M)`。
- 平衡形变量 `eEq=F mA/(kM)`；解析形变 `e(t)=eEq+(e0−eEq)cos(ωt)`，相对速度 `ė(t)=−ω(e0−eEq)sin(ωt)`。
- 相对加速度 `ë(t)=−ω²(e0−eEq)cos(ωt)`；`aA=aCM−(mB/M)ë=ke/mA`，`aB=aCM+(mA/M)ë=(F−ke)/mB`。
- `vA=vCM−(mB/M)ė`，`vB=vCM+(mA/M)ė`。这些等式作为实现交叉校验。
- `F=0,e0=0` 时系统静止；`F=0,e0≠0` 时质心静止、两物块作相对振动；`e0=eEq` 时两物块保持恒定间距并以 `F/M` 共同加速；初始 `e0=0` 时 `aA(0)=0`、`aB(0)=F/mB`。

### 2.3 教学重点与易错点

- 弹簧力由形变量决定，不能在整个过程中当作恒力；B 的外力恒定不代表 B 的合力或加速度恒定。
- 弹簧力是 A、B 间的内力，对系统整体求和时相互抵消，因此质心加速度恒为 `F/M`；单个物块的加速度可变且一般不同。
- 形变量可正可负，弹簧力方向随伸长/压缩改变；页面显示带符号 `ke`，读数面板另显示力的大小。
- 相对振动叠加质心平动；画面采用跟随镜头，刻度反向滚动并同步给出 `xCM`，不把视窗固定误解为质心静止。

## 3. 产品需求与交互方案

### 3.1 区块与画面

页面自上而下为：标题说明 → 单 Canvas 场景 → 播放/暂停/重置、倍速及时间控制 → `e-t` 与 `a-t` 双图 → 参数与实时数据双栏 → 模型方程和规律 → 图例/键盘说明。

- 场景画出水平轨道、A/B 物块、弹簧、外力 F 与弹簧对两物块的力；箭头带方向及标签，同一时刻按共同像素/力值比例绘制并限制最长尺寸。`F=0` 或弹簧力为零时对应箭头隐藏。画面另标 `e`、有符号 `ke`、`aCM` 和 `xCM`，并提示视角跟随质心。
- 颜色：A 蓝、B 橙、弹簧青、外力红。两物块分处弹簧两侧；屏幕中线按质量加权定位为质心，摄像机跟随质心、轨道刻度滚动。
- 图像：`e-t` 展示有符号形变量及平衡形变 `eEq` 虚线；`a-t` 展示 A/B 加速度及 `aCM` 虚线。时间游标与动画和数据同步。
- 实时数据：t、e、`|ke|`、`aA`、`aB`、`aCM`、`vA`、`vB`、`eEq`。

### 3.2 控件与状态

- 参数滑条：`mA`、`mB`、`k`、`F`、`e0`，范围和单位见 §2.1；参数改变即回到 `t=0` 并重算。
- 播放速度：0.5×、1×、1.5×、2×；开始/继续、暂停、重置；播放中锁定物理参数。
- 时间进度条可定位 `0–12 s`；定位时暂停动画。提供 `−0.1 s` / `+0.1 s` 单步检查，并保持图、画面和数据同步。
- 空格键切换播放/暂停或继续；R 重置。演示到 12 s 结束，重置后可重新播放。
- 所有 Canvas 按设备像素比适配；布局在桌面、约 800px 和约 390px 手机视口均可用，手机图表纵向排列、无水平溢出。

| 用例 | 输入/时刻 | 预期判据 |
|---|---|---|
| 默认初始值 | `mA=mB=1,k=20,F=4,e0=0,t=0` | `e=0, ke=0, aA=0, aB=4, aCM=2 m/s², eEq=0.1 m` |
| 默认四分之一相对周期 | `t=π/(2ω)`, `ω=√40` | `e=0.1 m, aA=aB=2 m/s²`（容差 0.01） |
| 默认半周期 | `t=π/ω` | `e=0.2 m, aA=4, aB=0 m/s²`（容差 0.01） |
| 平衡初态 | `e0=eEq=0.1 m` | `e` 恒定；`aA=aB=aCM=2 m/s²` |
| 无外力自由振动 | `F=0,e0=0.2 m` | `aCM=0,e=0.2cos(ωt)`；两物块质心坐标不变 |
| 全静止特例 | `F=0,e0=0` | 所有速度、加速度、弹簧力均为 0；无 NaN/Infinity |
| 压缩边界 | `F=0,e0=−0.5 m,t=0` | `e=−0.5 m, aA=−k·0.5/mA, aB=+k·0.5/mB`；弹簧长度仍正 |
| 最大参数 | `mA=mB=0.5,k=50,F=12,e0=0.5` | 有限值；`aA=ke/mA`、`aB=(F−ke)/mB`、`mAaA+mBaB=F` |
| 参数同步重算 | 播放后更改任一参数 | 时间回到 0，曲线、形变、力、加速度与速度均按新参数更新 |
| 暂停/单步/进度 | 暂停后 `+0.1 s`、拖动时间条 | 当前时刻更新；图表竖线、主场景、所有读数一致 |
| 结束和重置 | 播放至 12 s，再重置 | 结束态停止并显示 12 s；重置为 t=0 且可重新播放 |
| 响应式与离线 | 1280、800、390px；本地 file URL | 无水平溢出/脚本异常；画布与控件可读，离线工作 |
