# 动量守恒演示网页 · 排版与优化需求

## 1. 背景与目标
- **对标文件**：`_repo/momentum-collision.html`（动量守恒定律—两球碰撞演示，仅存在于仓库内）。
- **风格参照**：`_repo/block-plate.html`（板块运动演示 通用版 v8），以其排版/视觉/交互为系列基准。
- **目标**：物理模型不动（完全弹性 / 完全非弹性的一维对心碰撞，动量守恒），把页面从"紫渐变 + 左右双栏 + 侧栏卡片"重排为板块运动页的"单列居中 + 双图表 + 双控制卡 + 状态行 + 图例"结构，并补齐系列一致性能力（数据面板实时刷新、双图回放、预览态预告、DPR 适配、无障碍）。
- **已核对（保持不变的物理口径）**：
  - 完全弹性：`v1' = ((m1−m2)v1 + 2m2v2)/(m1+m2)`，动能守恒。
  - 完全非弹性：`v' = (m1v1+m2v2)/(m1+m2)`，共速，动能损失 `ΔEk = ½·m1m2/(m1+m2)·(v1−v2)²`。
  - 总动量全程守恒；碰撞由半径接触触发；画布左右为单向出口（滑出即结束）。

## 2. 现状问题清单（本次修复）
- **P0-排版**：紫色渐变背景、渐变标题/公式条、canvas 800×500 + 右侧 320px 侧栏的双栏结构，与系列单列风格完全不一致。
- **P0-图表缺失**：无 v-t 图；无 p-t 图（无法直观展示"总动量恒为水平线"这一守恒核心证据）。
- **P0-数据不实时**：动量/动能仅在碰撞瞬间更新，运行中面板不刷新。
- **P1-标尺刻度错误**：地面标尺用 `i/60*1+'m'` 固定假定 60px/m，画布自适应后刻度与实际位置错位。
- **P1-动量条溢出**：`drawMomentumBar` 固定 `maxP=60`，而 m·v 最大可到 20×5=100，条形会溢出量程。
- **P2-交互不一致**：运行中滑条"可拖但无效"（系列惯例为禁用）；无暂停/继续 disabled 态管理；无预览态联动与预告；无 DPR 适配、无 aria。

## 3. 功能需求

### FR1 页面结构重排（P0，核心）
对齐板块运动页的单列结构（max-width 880px 居中）：
```
h1「动量守恒演示｜高中物理」
→ 主场景画布（canvas-wrap，蓝框 2px #3388dd、圆角 10px、底色 #0b1828、880×520 基准）
→ charts-row 双图面板（左 v-t，右 p-t）
→ control-panel 双卡（左「参数设定」，右「实时数据显示」）
→ actions 按钮行（开始 / 暂停 / 重置，居中）
→ status 状态行（预览态预告 / 结束总结）
→ legend 图例（球A/球B/速度箭头/曲线配色/公式）
```
- 移除：紫渐变背景、渐变文字标题、渐变公式条、`.main-area` 双栏布局、渐变彩色按钮。
- 守恒公式 `m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′` 移入页面底部 legend 行展示（弱化，不再单独成卡）。
- 全局配色对齐板块页：`body #121212`、卡片 `rgba(255,255,255,0.05)` + 1px 边框、标题纯白、辅助字 `#8899aa`。

### FR2 主场景画布重绘（P0）
- 基准 880×520（与板块页一致），DPR 缩放；小球改为蓝 `#3399ff`（球 A）与灰 `#8a8f98`（球 B），速度箭头黄 `#ffdd57`。
- 保留：球体径向渐变、质量标注、速度箭头+数值、拖尾、碰撞粒子特效、碰撞瞬间画面提示。
- 地面标尺改为**世界坐标刻度**：以球 A 初始位置为 0 点按米标注（或按画布中轴 0 点），随画布宽度自适应，修掉 60px/m 假定错位。
- 动量条形图（A/B/Σp 三行、零线对齐）保留在画布顶部，量程按 `max(|pA|,|pB|,|Σp|)×1.2` 动态计算，修复溢出；配色与图例一致（A 蓝、B 灰、Σp 橙 `#ffaa22`）。
- 正方向标注 `正方向 →` 移到画布左上角（同板块页）。

### FR3 双图表 charts-row（P0）
参照板块页 chart-panel 样式（深色卡 + 内嵌 canvas 20/9 比例）：
- **左图 v-t**：vA 蓝线、vB 灰线；零线；碰撞时刻竖虚线并标注「碰撞 t=…s」；播放头圆点。
- **右图 p-t**：pA 蓝线、pB 灰线、Σp 橙线（**水平直线，动量守恒的直接证据**）；碰撞时刻同步虚线；播放头。
- 轴标签 `t (s)` / `v (m/s)` / `p (kg·m/s)`、网格、图内小图例，均与板块页画法一致。
- 未开始时图内显示「开始后将显示 v-t 图 / p-t 图」占位。

### FR4 控制面板双卡（P0）
- **参数设定卡**：碰撞类型（完全弹性 / 完全非弹性 二选一）、球A质量、球A初速度、球B质量、球B初速度、动画速度（0.5×–3×）。滑条范围沿用现值（质量 1–20kg、速度 ±5m/s）。
- **实时数据显示卡**（data-grid 3 列小卡，`aria-live="polite"`）：vA、vB、pA、pB、总动量 Σp、总动能 Ek、碰撞状态（待开始/已碰撞/未碰撞）、碰撞时刻。运行中**逐帧实时刷新**；数值 tabular-nums。
- 颜色语义：A 蓝、B 灰、Σp 橙、动能绿 `#33dd66`。

### FR5 执行架构：预仿真 + 回放（P0，与板块页统一）
- 物理公式不变，但改为板块页同款**预仿真+回放**：
  - 碰撞时刻 `t* = (|x0B − x0A| − rA − rB) / |v0A − v0B|` 解析求得（同向追赶/相向均可）；
  - 碰后速度按所选类型解析求解，生成 T/VA/VB/PA/PB 序列，逐帧插值回放；
  - v-t、p-t 图与场景动画共用同一播放头，天然同步。
- 两球不会碰撞的情形（v0A ≤ v0B 同向慢追不上、背向而行、等速）在序列中标记，状态行预告并让球滑出画布结束。

### FR6 按钮与状态机（P0）
- 开始 / 暂停（同钮切「继续」）/ 重置；disabled 逻辑照抄板块页：idle 时仅开始可用；running 时开始禁用；ended 后仅重置可用。
- 运行中**禁用全部参数滑条**（opacity 0.45）；结束后拖动滑条经 previewGuard 自动回到预览态（同板块页）。
- 空格 toggle 开始/暂停/继续、R 重置；焦点在表单元素时不触发（系列惯例）。

### FR7 预览态联动与预告（P1）
- idle 拖动滑条即时重绘场景预览 + 按当前参数重算预测。
- 状态行预告，示例：
  - 可碰撞：「当前参数：t = 0.80 s 发生完全弹性碰撞，碰后 vA′ = −1.25 m/s、vB′ = 2.75 m/s；总动量 9.0 kg·m/s 保持不变，总动能守恒。」
  - 非弹性补充动能损失：「总动能 31.5 J → 22.1 J，损失 9.4 J（转化为内能）。」
  - 不可碰撞：「当前参数：两球不会相遇（无相对接近速度）。」
- 结束态总结：碰前/碰后 Σp 与 Ek 对比一句话结论。

### FR8 适配与无障碍（P1/P2）
- setupCanvas + devicePixelRatio + ResizeObserver（三块画布统一）。
- 三个 canvas 均加 `role="img"` + 中文 `aria-label`；数据卡组 `aria-labelledby` + `aria-live`（播放中置 off，暂停/结束/恢复 polite，同系列）。
- 窄屏（≤720px）charts-row、control-panel 折为单列（沿用板块页断点）。

### FR9 文案与注释（P2）
- 标题/图例/数据卡全面中文；文件头注释块按板块页格式改写（文件描述、物理内容、本次 v2 变更、适用场景、风格声明）。

## 4. 风格 / 一致性
- 深色主题、卡片、圆角、字级、按钮态、group-title、legend 全部对齐 `_repo/block-plate.html`，不引入新组件样式。
- 色板收敛为系列色：蓝 `#3399ff`、灰 `#8a8f98`、橙 `#ffaa22`、黄 `#ffdd57`、红 `#ff4444`、绿 `#33dd66`、强调框 `#3388dd`。

## 5. 非目标（本次不做）
- 不改碰撞物理公式与碰撞触发判定；不引入恢复系数 e 滑条（仅弹性/非弹性两档）。
- 不做二维斜碰、墙壁反弹、重力/抛体扩展。
- 不新增 s-t 图（两球匀速直线，教学价值低）。
- 不做键盘左右微调球位置等新交互。

- [ ] 主画布蓝框 880×520 基准、DPR 适配、窗口缩放不模糊不错位；地面刻度为真实米坐标。
- [ ] 画布顶部动量条 A/B/Σp 不再溢出，量程随参数自适应。
- [ ] v-t 图两线正确；p-t 图 Σp 为水平直线（弹性与非弹性均守恒）；碰撞时刻双图同步虚线标注。
- [ ] 数据卡运行中逐帧刷新，含 vA/vB/pA/pB/Σp/Ek/碰撞状态/碰撞时刻。
