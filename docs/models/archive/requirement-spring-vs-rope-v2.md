# 弹簧 vs 绳子演示网页 · v2 重写需求

## 1. 背景与目标
- **对标文件**：`spring-vs-rope-demo.html`（弹簧 vs 绳子 · 哪个球先落地？）
- **在线地址**：https://wenqiaowuli.github.io/demo/spring-vs-rope-demo.html
- **前置**：v1（双画布分屏/弹簧振荡/自由落体/结论区）已上线。
- **目标**：重写为单画布 + 图表 + 标准控制面板布局，对齐系列骨架。
- **参照**：`projectile-motion.html`——主画布 880:520 蓝框、图表 20:9、control-panel 左右分栏、actions 独立区。

## 2. 改动清单

### R1 主画布合并
- 原双画布（`canvasA` 520×560 + `canvasB` 520×560）→ **单画布 `880×520`**。
- CSS：`aspect-ratio: 880/520`，`border: 2px solid #3388dd`，`border-radius: 10px`，`background: #0b1828`。
- 两球并排：A 球（弹簧悬挂）在左侧（x ≈ 33%），B 球（绳子悬挂）在右侧（x ≈ 67%）。
- 场景元素：顶部支点支架 ×2、弹簧（A 侧锯齿折线）、绳子（B 侧直线）、地面线 + 阴影斜线。
- 初始状态：两球等高，标注虚线 + "两球等高 h=X.Xm"。
- 剪断动画：剪刀图标 + 闪光，两侧同时剪断。

### R2 图表区
- `charts-row`：v-t 图 + s-t 图并排，`gap: 14px`。
- 图表画布：`aspect-ratio: 20/9`，`border: 2px solid #3388dd`，`background: #0b1828`。
- v-t 图：A 球速度（蓝）+ B 球速度（红），阴影 = 速度差。
- s-t 图：A 球位移（蓝）+ B 球位移（红），阴影 = 位移差。
- 纵轴自适应，零线加粗，当前点圆点，滑动时间窗 10s。

### R3 控制面板
- 左侧 `.param-group`：下落高度 h、弹簧刚度 k、质量 m、阻尼比 ζ、播放速度（共 5 个滑条）。
- 右侧 `.data-group`：9 项实时数据（3 列 grid）——时间 t、A 球速度/加速度、B 球速度/加速度、弹簧形变 Δx、A/B 球位移、位移差 Δs。
- 底部 `fixed-note`：物理要点说明（g=10 固定值）。
- **无单独的重力 g 滑条**（g 固定为 10 m/s²）。

### R4 操作按钮
- 三个按钮：▶ 开始 / ⏸ 暂停（含继续，同一按钮切换） / ⟲ 重置。
- 独立 `.actions` div，位于 `control-panel` 与 `legend` 之间。
- 暂停/继续合并：点击暂停后按钮文字变为"▶ 继续"，再点击恢复运行。

### R5 图例
- A 球（弹簧悬挂）、B 球（绳子悬挂）、弹簧 (k·x)、键盘快捷键。

### R6 物理模型
- A 球（弹簧）：剪断瞬间弹簧形变不能突变，弹力 = kx₀ = mg，初始 a = 0；整体下落 + 共落系内阻尼简谐振荡。
- B 球（绳子）：剪断瞬间张力立即消失，立即自由落体 a = g。
- **g 固定为 10 m/s²**，无滑条调节。
- 默认参数：h=7m、k=25N/m、m=1kg、ζ=0.12。

### R7 交互
- 空格 = 开始/暂停/继续，R = 重置。
- 运行/暂停中禁用所有滑条；idle/done 态可调参数并自动重置。
