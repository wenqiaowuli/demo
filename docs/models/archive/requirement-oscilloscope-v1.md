## 三、物理模型与统一几何约定
### 3.1 固定常量
1. 粒子为电子。电子电荷量用正值大小表示 `e = 1.6×10⁻¹⁹ C`，电子质量 `m = 9.1×10⁻³¹ kg`；初速度视为零。
2. 使用高中理想模型和非相对论公式；常量在公式说明框中固定显示。
3. 加速电压 U1 始终为正，范围 500~2000 V。

### 3.2 正交偏转区（必须按此定义实现）
1. 两组偏转极板不是沿电子运动方向前后串联的两个区域，而是**同一个正交偏转区内相互垂直的两组极板**：
   - 上下两块水平放置的极板（YY 极板）负责竖直偏转；
   - 左右两块竖直放置的极板（XX 极板）负责水平偏转。（**v1.3 修订：极板画法改为课本串联布局，见第二十节 20.1；本节 L、d、L′、K 等物理等效口径不变，仍按下列条款执行**）
2. 两组极板沿电子运动方向占据相同的有效长度 `L = 4 cm`，极板间距均为 `d = 1 cm`，共同从同一偏转区入口到同一出口；两组偏转场在理想模型中可独立叠加。（“同一入口到同一出口”为**等效物理口径**，指两方向使用相同的 L 与等效 L′；实际画法按 v1.3 串联布局，见第二十节 20.1）
3. 偏转区出口到荧光屏的距离为 `L′ = 18 cm`。荧光屏有效范围为 `±6 cm × ±6 cm`，主网格 2 cm，副网格 1 cm。
4. 侧视图只直接绘制 YY 方向的上下极板和竖直轨迹；XX 极板在同一位置以透视/半透明交叉结构表示，不能画成位于 YY 区之后的第二个独立偏转区。（**v1.3 修订：已改为 YY′ 在前、XX′ 在后的课本串联画法，见第二十节 20.1**）水平偏转轨迹在侧视图中以虚线投影或“出纸面方向”标注，实际偏移在右侧荧光屏正面图中呈现。
5. 两个方向严格使用相同的几何系数，保证 X/Y 对称：
   - `K = L(L + 2L′)/(4d) = 0.4 m`
   - `X = K·Ux/U1 = 0.4·Ux/U1（m）`
   - `Y = K·Uy/U1 = 0.4·Uy/U1（m）`

### 3.3 方向与符号约定
- `Uy > 0`：上极板为正，电子受力向上，屏上亮点向上；`Uy < 0`：亮点向下。
- `Ux > 0`：右极板为正，电子受力向右，屏上亮点向右；`Ux < 0`：亮点向左。
- 模式二的 `Ay`、`Ax` 是非负幅度；瞬时电压由波形函数决定，正负方向由函数相位/扫描方向产生。
- 屏幕绘图坐标以屏中心为原点，数学坐标 y 轴向上；Canvas 像素坐标换算为 `screenPixel = center + (X, −Y)·pxPerCm`。

### 3.4 运动分解与成像公式
以任意一个偏转方向为例，另一个方向完全对称：
1. 加速：`eU1 = ½mv₀²`，因此 `v₀ = √(2eU1/m)`。
2. 偏转场：`E = U偏/d`，加速度大小 `a = eU偏/(md)`；进入极板后运动时间 `t = L/v₀`。
3. 板内侧移：
   - `s偏 = U偏L²/(4dU1)`；
   - 竖直方向记为 `y`，水平方向记为 `x`。
4. 出射角：`tanθ = U偏L/(2dU1)`。
5. 出偏转区后做匀速直线运动，屏上偏移：
   - `Y = (L/2 + L′)·tanθy = UyL(L+2L′)/(4dU1)`；
   - `X = (L/2 + L′)·tanθx = UxL(L+2L′)/(4dU1)`。
6. 教学要点（公式说明框必须呈现）：
   - U1 增大 ⇒ `v₀ ∝ √U1` 增大、通过偏转区时间变短、相同偏转电压下亮点/波形向中心收缩，偏转灵敏度 `K/U1 ∝ 1/U1`；
   - Ux 或 Uy 的绝对值增大 ⇒ 对应方向偏移增大，方向由极性决定；
   - 成像位置由 `Ux/U1` 与 `Uy/U1` 两个比值决定，偏转电压与加速电压存在竞争关系；
   - 实际示波器使用水平锯齿扫描和竖直信号电压，使屏上的亮点轨迹展开为波形。

### 3.5 打极板与屏幕边界
1. 每一方向的板内侧移超过半间距即撞击对应极板：
   - `|y| > d/2` ⇔ `|Uy| > 0.125·U1`：撞击 YY 极板；
   - `|x| > d/2` ⇔ `|Ux| > 0.125·U1`：撞击 XX 极板。
2. `|s偏| = d/2` 为临界状态：电子恰沿极板边缘通过，提示“临界：恰沿极板边缘通过”；严格大于临界才判定“电子打在极板上”。
3. 固定几何下，打极板临界对应的屏上偏移恒为：
   - `K·0.125 = 0.4×0.125 = 0.05 m = 5 cm`。
   - 因此屏边界为 ±6 cm，而电子在本模型中会先在 ±5 cm 临界处打极板；“亮点出屏”在模式一和模式二均结构性不可达，不设置为独立状态。
4. 两个方向同时超限时，状态提示优先显示“电子同时打在 XX、YY 偏转极板上”；单方向超限时显示具体方向；模式二按时间采样点局部判定，不因一个采样点超限而让整条波形消失。

## 五、两种演示模式与参数语义
模式切换位于参数面板顶部。两种模式的参数含义不能混用；U1 为公共参数，各模式保存自己的偏转参数。

### 5.1 模式一：偏转演示（默认）
- U1：加速电压，正值直流，范围 500~2000 V。
- Uy：竖直直流偏转电压，范围 −100~+100 V；上下极板电压差的等效带符号值。
- Ux：水平直流偏转电压，范围 −100~+100 V；左右极板电压差的等效带符号值。
- 屏上显示一个静态亮点 `(X,Y)`；拖动滑条或拖动亮点时实时更新。
- 模式一使用亮点移动拖尾约 1 s；不绘制连续波形。

### 5.2 模式二：波形扫描
#### 参数含义
- U1：公共加速电压，范围 500~2000 V。
- Ay：竖直信号峰值，非负，范围 0~100 V；`Uy(t)` 的峰值。
- Ax：水平扫描幅度，非负，范围 0~100 V；`Ux(t)` 在 `−Ax` 与 `+Ax` 之间扫描。
- 模式二默认值：`U1=1000 V、Ay=50 V、Ax=80 V、播放速度=1×`。此时波形包络约为 `X=±3.20 cm、Y=±2.00 cm`，不触发极板碰撞。
- `Ay=0` 时屏上为水平基线；`Ax=0` 时失去水平展开，仅作为退化情形保留，不作为默认演示状态。

#### 扫描函数与时间规则
1. 名义频率关系：信号 `f_signal=50 Hz`，扫描 `f_scan=25 Hz`，即 `T_scan=2T_signal`；这个频率只定义相位关系，动画采用教学慢放，不模拟真实 25/50 Hz 的刷新速度。
2. 每个扫描周期由“正向扫描 + 回扫”组成：
   - 正向扫描阶段，`q` 从 0 线性变化到 1，`Ux(t) = −Ax + 2Ax·q`；
   - 同一阶段，`Uy(t) = Ay·sin(4πq + φ0)`，正好显示两个完整正弦周期；`φ0` 固定为 0，不提供额外相位控件；
   - 到达右端后进入短暂回扫阶段（建议占一个扫描周期的 8%~12%），`Ux` 快速回到左端；
   - **回扫阶段电子束熄灭/不写入波形缓冲**，屏上不得出现从右端斜连回左端的非物理亮线；
   - 正向扫描重新开始后写入下一条波形。
3. 1× 播放速度下，一个完整扫描周期建议映射为约 4 s；播放速度只改变动画时间，不改变“一次扫描包含两个信号周期”的比例。
4. 波形缓冲保留最近两个完整扫描周期；新周期完成后再淘汰最旧周期，保证用户始终能看到完整波形。

#### 模式二碰板与波形缺失
- 对每个采样点独立判定：
  - `|Uy(t)| > 0.125·U1`：该采样点撞击 YY 极板，波形在上下方向缺失/削顶；

1. **加速电压的影响（0~3 s）**：Uy 固定 +50 V，Ux=0；U1 从 500 V 缓升到 2000 V。全程不打极板（`0.125×500=62.5 V > 50 V`），亮点从 +4.00 cm 连续收缩至 +1.00 cm；电子束间距拉大。
2. **竖直偏转的影响（3.5~6 s）**：U1=1000 V、Ux=0；Uy 从 −100 V 扫到 +100 V，亮点自下而上通过屏中心并留下竖直余辉轨迹。
3. **水平偏转的影响（6.5~9 s）**：U1=1000 V、Uy=0；Ux 从 −100 V 扫到 +100 V，亮点自左向右通过屏中心并留下水平余辉轨迹。
4. **回默认（9~10 s）**：从过渡起点 `U1=1000 V、Uy=0、Ux=+100 V` 平滑恢复模式一默认 `U1=1000 V、Uy=+50 V、Ux=0`，结束后回到 idle。

- **3.0~3.5 s 参数过渡**：U1 从 2000 V 平滑回落到 1000 V，Uy 从 +50 V 平滑变为 −100 V，Ux 保持 0；此段只用于衔接，不计入竖直扫动时长。
- **6.0~6.5 s 参数过渡**：Uy 从 +100 V 平滑变为 0，Ux 从 0 平滑变为 −100 V，U1 保持 1000 V；此段只用于衔接，不计入水平扫动时长。
- 验证点：3.25 s 应处于“竖直偏转准备/过渡”，6.25 s 应处于“水平偏转准备/过渡”，不得将这两个时刻误报为完整主阶段。

  - `Uy = Y_cm·U1/40`；
  - `Ux = X_cm·U1/40`；

- 可拖区域直接限制在有效范围内，拖到边界即停、无回弹：

## 十一、物理公式与几何（实现参考，勿改动）
- `v₀ = √(2eU1/m)`，`e = 1.6×10⁻¹⁹ C`，`m = 9.1×10⁻³¹ kg`。
- `Ey = Uy/d`，`Ex = Ux/d`。
- `ay = eUy/(md)`，`ax = eUx/(md)`。
- `t = L/v₀`。
- `y = UyL²/(4dU1)`，`x = UxL²/(4dU1)`。
- `tanθy = UyL/(2dU1)`，`tanθx = UxL/(2dU1)`。
- `Y = (L/2+L′)·tanθy = 0.4·Uy/U1（m）`。
- `X = (L/2+L′)·tanθx = 0.4·Ux/U1（m）`。
- 几何：`L=0.04 m`，`d=0.01 m`，`L′=0.18 m`，`K=0.4 m`，屏 ±6 cm。
- 关键值：U1=500/1000/2000 V 时，`v₀=1.33/1.88/2.65×10⁷ m/s`（√3.5165×10¹⁴ = 1.875×10⁷，两位小数标准舍入为 1.88；实现与验收均按 1.88），`t=3.02/2.13/1.51 ns`；灵敏度分别为 0.8/0.4/0.2 mm/V。
- 碰板临界：`|U偏|=0.125·U1` 对应板内侧移 5 mm、屏上偏移 5 cm；严格大于该值判定撞击极板。
- 侧视图 YY 轨迹：以 YY 区入口为原点、x 沿管轴，按类平抛解析式逐点绘制；XX 同一区域的水平分量在正面屏图中呈现，不在侧视图伪造第二个纵深区域。

## 十二、理想模型边界（实现范围）
本页只服务高中物理定性与定量演示，不追求真实示波器工程细节，不实现以下因素：
- 管内空间电荷效应和电子束之间的相互作用；
- 偏转极板边缘电场、场区非均匀性和真实极板形状修正；
- 电子初速度分布、热发射速度差异、散射和束流发散；
- 相对论速度修正；
- 荧光粉真实余辉曲线、亮度控制、聚焦/辉度电极和真实触发同步；
- 真实示波器的输入阻抗、带宽、噪声、触发模式和扫描校准。

实现必须保留的教学核心只有：
1. 加速电压改变电子速度；
2. 两个正交偏转电压改变两个方向的轨迹；
3. 屏上位置由偏转电压与加速电压的比值决定；
4. 水平扫描与竖直信号共同形成屏上波形；
5. 加速不足或偏转过大时电子会撞击偏转极板。

### 16.1 模式二波形笔画边界（必须修复）
- 当前/首版常见错误：仅在扫描进度从周期末回到 0 时关闭笔画，进入回扫阶段时没有立即结束当前笔画，可能导致回扫后新周期与旧周期首尾相连。
- 正确规则：当扫描进度第一次跨过正扫结束边界 `fwd = 1 − RETRACE`（即 `p0 ≤ fwd` 且 `p1 > fwd`）时，立即结束当前正向扫描笔画；回扫阶段不向当前笔画写入任何点；下一次正扫开始时创建新笔画。
- 每个周期的最后一个有效点和下一个周期的第一个有效点之间必须有断笔标记/独立路径，绝不能有横向回扫线。
