# 水平直线运动演示 · v4 演示窗口尺寸对齐需求

## 1. 背景与目标
- **对标文件**：`horizontal-linear-motion.html`（水平直线运动演示）。
- **参照**：`block-plate.html`（板块运动演示）主画布 `#scene` 为 880×520 基准（蓝框 2px #3388dd、圆角 10px）。
- **现状**：水平直线运动主画布为 880×440（`aspect-ratio: 880/440`、`BASE_HEIGHT = 440`），演示窗口面积与板块运动页不一致。
- **目标**：将主画布尺寸调整为 880×520，与板块运动页演示窗口**同宽同高、线框面积一致**。

## 2. 改动点
- **CSS**：`canvas#scene` 的 `aspect-ratio: 880 / 440` → `880 / 520`。
- **JS**：`BASE_HEIGHT = 440` → `520`（`resizeAll` 的 `setupCanvas(sceneCanvas, sceneView, BASE_WIDTH / BASE_HEIGHT)` 随之自动适配）。
- **内部布局适配**：场景绘制全部基于 `sceneView.height` 相对布局（`axisY = round(height × 0.56)`），高度变化后自动适配（246 → 291），x 轴、刻度、±20m 越界虚线、小球、v/a 矢量、轨迹等绘制逻辑**一行不改**。

## 3. 非目标（本次不做）
- 不改 v-t / s-t 双图尺寸（维持 20/9 比例与 400×180 基准）。
- 不改参数面板、按钮、图例、数据卡与任何文案。
- 不改物理逻辑（匀变速公式、越界判定、暂停/继续/重置、快捷交互）。

## 4. 验收标准
- [ ] 主画布线框与板块运动页同宽同高：880×520 基准（CSS aspect-ratio 与 JS BASE_HEIGHT 一致为 880/520）。
- [ ] 窗口缩放时主画布保持 880/520 比例（DPR + ResizeObserver 沿用），内部元素不拉伸、不错位。
- [ ] x 轴轴线、刻度标签、越界虚线、'+20m/-20m' 标注、矢量文字均完整落在画布内，无被裁切。
- [ ] 双图、面板、交互、物理行为无回归。
