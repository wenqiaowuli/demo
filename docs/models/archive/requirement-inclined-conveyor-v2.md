# 倾斜传送带演示网页 · 改版需求 v2

## 1. 背景与目标

- **对标文件**：`inclined-conveyor-belt.html`（倾斜传送带 · 动力学演示）。
- **发布位置**：与水平版相同目录 `https://wenqiaowuli.github.io/demo/inclined-conveyor-belt.html`。
- **前置**：v1 现状——左右两栏布局（动画｜控制）、单 v-t 图、固定力箭头、两处离带文案错误、θ≤28° 画布裁切、"带向上 + μ<tanθ + 轻放"场景瞬间结束不可见。
- **参照（布局风格基准）**：`horizontal-conveyor-belt.html`——`标题 → 主画布 → 图表行(v-t|s-t) → control-panel(左参数卡|右数据卡) → 图例 → footer`，纯黑主题、#3388dd 主色、param-row 单行控件、3 列数据卡、开始/暂停/继续/重置状态机、空格/R 快捷键、运行中禁用滑条。
- **目标（v2）**：布局风格全面对齐水平版；修复 v1 确认的 Bug；补齐教学呈现（等比力箭头、摩擦力数值与性质、双速度箭头、s-t 图、共速标注）。

### 已确认决策
1. **新增 s-t 图**（双图并排，两线间距 = 相对位移）。
2. **正方向保持"沿斜面向上为正"**（仅布局对齐，不改物理约定；v-t/s-t 纵轴允许负值）。
3. **方向控件单滑条化**：v带、v₀ 均为 ±5 m/s 滑条，正 = 沿斜面向上、负 = 向下、0 = 静止；删除"向上/向下"与"沿斜面上/下"两组方向按钮。
4. **可选功能取舍**：取 播放倍速、带长 L、重力 g（默认 10）、带面相对滑动擦痕；不取 摩擦生热 Q（留作 v3）。
5. **结论提示卡**：精简后并入参数卡 fixed-note 公式框，删除独立结论卡。
6. **默认情景**：θ=30°、μ=0.50、v带=−2 m/s（向下）、v₀=0、初始位置=顶端——开机即"带向下两段加速"经典考点。

## 2. 改动清单

### 组A · 布局与风格对齐（对齐水平传送带）

### L1 页面骨架
- DOM 顺序：`h1 → subtitle → main(canvas-wrap → charts-row → control-panel → legend) → footer`。
- `charts-row`：v-t 与 s-t 双面板并排（grid 2 列，<720px 单列）。
- `control-panel`：grid 2 列（左参数卡 + 右数据卡，gap 14px），<720px 单列。

### L2 视觉主题
- 背景 `#121212`；卡片 `rgba(255,255,255,0.04)` + 1px `rgba(255,255,255,0.1)` 边框 + 圆角 10px。
- 按钮实心 `#3388dd`（hover `#4499ee`），辅助按钮 `.alt` `#445566`；滑条 accent `#3388dd`。
- 图表画布带 2px `#3388dd` 边框、背景 `#0b1828`；主画布背景 `#0d141b` + 24px 淡网格。
- 文字灰阶：标题 `#e8eef5`、卡题 `#8899aa`、说明 `#667788`。

### L3 参数行与数据卡风格
- 参数行：`label(110px) + 滑条(flex) + 数值(70px 右对齐, tabular-nums)` 单行式。
- 数据卡：3 列 grid（<560px 变 2 列），`.data-item`（10px 标签 + 15px 数值），彩色强调（橙/绿/青）。

### L4 运行控制状态机
- 状态机 `idle | run | pause | done`；按钮 ▶开始 / ⏸暂停 / ▶继续 / ⟲重置。
- 空格 = 开始/暂停/继续，R = 重置（焦点在 INPUT/SELECT/TEXTAREA/BUTTON 时忽略）。
- done 态：开始按钮置灰显示"已离开"，重置无条件恢复 idle（见 L14 组语义）。

### L5 方向参数单滑条化
- 带速滑条 `vb`：−5 ~ +5 m/s，步长 0.1，默认 **−2**（负 = 沿斜面向下）。
- 初速度滑条 `v0`：−5 ~ +5 m/s，步长 0.1，默认 0。
- 正负号与 v-t 图纵轴符号一致（沿斜面向上为正）。

### L6 参数卡内容
- 滑条：倾角 θ（5–60°，步长 1，默认 30）、初速度 v₀、带速 v带、动摩擦 μ（0.05–1.5，步长 0.01，默认 0.50）、重力 g（5–15，步长 0.1，默认 10）、带长 L（4–20 m，步长 1，默认 10）、播放速度（0.25–4×，步长 0.25，默认 1×）。
- 初始位置按钮：`⬒ 底端` / `⬒ 中部` / `⬒ 顶端`（互斥，当前项置灰；底端=1 m、中部=L/2、顶端=L−1 m，改 L 后按语义自适应端部）。
- 底部 `fixed-note` 公式框（替代原结论卡）：
  - 滑动摩擦：`f = μmg·cosθ`，`a = −g·sinθ ∓ μg·cosθ`（与相对滑动方向相反）
  - 共速条件：`μ ≥ tanθ ↔ 静摩擦可维持共速（f静 = mg·sinθ）`
  - 带向上·轻放：μ>tanθ 先 `a=μg·cosθ−g·sinθ` 上行、共速后匀速；μ≤tanθ 无法上带
  - 带向下·轻放：先 `a=g·sinθ+μg·cosθ`；共速后 μ≥tanθ 匀速下行，μ<tanθ 以 `a=g·sinθ−μg·cosθ` 继续加速
  - 正方向：沿斜面向上为正（v带、v₀ 正负表示方向）
  - 参数：m=1 kg · g · μ · θ · v带 · v₀ · L

### L7 数据卡内容（10 项，3 列 grid）
1. 物块速度 v（橙，带符号）
2. 传送带速度 v带（青，带符号）
3. 相对带速 v−v带（橙，带符号；离带显示 —）
4. 加速度 a（带符号）
5. 摩擦力 f（绿，恒为大小）
6. 摩擦性质（滑动摩擦 / 静摩擦 / 无（已离带））
7. 支持力 N = mg·cosθ
8. 位置 s（沿带坐标，底端=0）
9. 已用时间 t
10. μ 与 tanθ（如 `0.50 < 0.58`，实时判定共速条件）

### L8 场景精绘（移植水平版元素）
- 金属渐变滚筒：8 辐条 + 双轮缘 + 空心轮毂（暗腔 + 内环 + 中心细轴）+ 旋转亮斑，随带速旋转。
- 环形带（沿斜面的平行四边形环带 + 两端半圆包角）：上承载/下回程，8px 主体 + ±4px 边缘线 + 斜纹纹理（上承载随带、下回程反向）。
- 机架支腿（两滚筒垂直接地）+ 横撑 + 地面线与斜线阴影。
- 带面红色滑动擦痕：带参考系记录 `q = s − v带·t`，偏移至物块后方外露区域（`off = −sign(v_rel)·半宽`），随带面平移，共速后定格，裁剪于 [0, L]。
- 放上点标记（绿三角 + 文字）、出料箭头（v带>0 在顶端、v带<0 在底端、0 不显示）。
- 带速指示：带中下方文字 `v带 = x.xx m/s` + 沿带方向小箭头（0 时显示"带静止"）。
- θ 角圆弧标注（底端滚筒处，弧 + `θ=xx°` 文字）、底端/顶端端点文字。

### L9 图表机制（对齐水平版）
- 滑动时间窗 10 s，nice 刻度（niceCeil/niceStep），零线加粗高亮。
- 当前时刻圆点标注；共速时刻绿色虚竖线 + `共速 t=x.xx s` 标注（仅当发生静摩擦维持时记录 tSync）。
- 两线间阴影（rgba(170,255,102,0.10)）= 相对位移，只覆盖已发生时间 [0, t]。
- v-t：物块 v 橙实线 + 带速 v带 青实线；s-t：物块位移 (s−s₀) 橙实线 + 带位移 v带·t 青实线。

### L10 运行态控件安全（统一交互语义）
- run/pause 态禁用全部参数滑条与初始位置按钮；idle/done 态修改参数或位置 → 完整 reset()。
- 播放速度滑条仅 readControls，不触发重置（运行中也可调倍速）。

### L11 无障碍与页脚
- 三块 canvas 均 `role="img"` + 中文 aria-label；数据卡 `aria-live`（运行时 off，其余 polite）。
- 页脚 `footer`：倾斜传送带模型 · 物块-传送带动力学演示 · 高中物理。

### 组B · Bug 修复（v1 确认）

### L12 画布几何全约束（修复 θ≤28° 顶端裁切）
- 缩放系数同时受宽度与高度约束：`pix = min(availW/(L·cosθ), availH/(L·sinθ))`，带体水平居中。
- 验收：θ∈[5°,60°] × L∈[4,20] 全组合，顶端滚筒 B、出料箭头、端点文字均不超出画布。

### L13 离带状态文案修复
- 按实际离开端别区分"已从顶端离开（匀速）/ 已从底端离开（匀速）"，绘制于物块上方。
- 删除 v1"μ≤tanθ：物体无法上行"的固定文案（该信息由数据卡 μ 与 tanθ 项实时呈现）。

### L14 μ<tanθ + 带向上 + 轻放场景可见性
- 初始位置默认 inset（底端=1 m），物块下滑过程全程可见（≥1 s）后自然从底端滑出。
- 底端/顶端起点不再精确压在滚筒圆心，物块不再骑在滚筒上。

### 组C · 教学呈现增强

### L15 受力箭头等比绘制
- 统一比例 `fs = 3.6 px/N`（m=1 kg）：G=mg、N=mg·cosθ、f 按真实大小等比缩放。
- 共速（静摩擦）时 f = mg·sinθ；滑动时 f = μmg·cosθ；离带后不绘制力箭头。

### L16 摩擦性质可视化
- 滑动摩擦箭头粉色 `#ff5577`，静摩擦箭头绿色 `#aaff66`；数据卡"摩擦性质"同步文字。

### L17 双速度箭头
- 物块上方平行绘制两支箭头：v物（橙，长度 ∝|v|）与 v带（青，长度 ∝|v带|），方向沿带、正负表向；尖端标注 v / v带。
- 滑动时其上方显示 `v相对 = ±x.xx m/s`（绿）；共速显示 `v相对 = 0（共速）`。

### L18 v-t 图纵轴非对称自适应
- `yMin = min(0, 负向极值×1.08)`（无负值则为 0）、`yMax = niceCeil(正向极值×1.05)`——单向运动不再浪费半幅。

### L19 新增 s-t 图
- 见 L9；纵轴覆盖物块位移与带位移（含反向初速度造成的负位移，不得裁掉）。

### L20 参数范围调整
- 带速滑条含 0（静止带对照）；μ 上限 1.5（θ>45° 时仍可 μ≥tanθ）；θ 角圆弧标注（L8）。

### L21 语义修正
- 数据卡"位移"改为"位置 s（沿带坐标，底端=0）"；真实位移由 s-t 图呈现。

### 组D · 工程健壮性

### L22 采样数组限长
- `trace` 上限 4000 条，超出裁剪至 3600（参照水平版）。

### L23 resize 自适应
- `fit()`：按 `getBoundingClientRect() × devicePixelRatio` 重建画布缓冲并 setTransform；window resize 时三画布全部重建后重绘。

### L24 物理积分细化
- 每帧 4 子步；子步内跨共速且静摩擦可维持时，解析推进至共速点（梯形积分）后锁定 v=v带；其余子步梯形积分 `s += (v+vNew)·h/2`。
- 离带后无摩擦匀速滑行 46px 后冻结（phase=done），不无限漂移。

### L25 调试钩子
- `window.__inclineDebug = { state, geom, getPhase }` 供无头验证与排查使用，不影响界面。

## 3. 保持不变（倾斜版特有）
- "沿斜面向上为正"的物理约定与 v-t 图符号体系。
- θ 滑条、tanθ 实时显示、μ 与 tanθ 共速判定。
- 摩擦力方向由"相对传送带滑动方向"决定的核心演示逻辑。
- m = 1 kg；物块 m 标签；g 可调（新增，默认 10 与水平版一致）。
