## 一、物块 A 形状与大小固定不变（需求 1）

1. **物块 A 恒为正方形**：无论运动状态（板上滑动 / 共速 / 滑出 / 落地滑行）、
   无论板长 L 如何调整，物块 A 的形状与大小都保持不变。
2. **实现约定**：物块世界尺寸固定为 `BLOCK_W_M = 2.0 m`（宽 = 高），
   像素尺寸 = 2.0 m × 比例尺，随画布宽自适应，但**不随板长 L、不随运动进程变化**。
3. 废除原"物块长度 = 板长 8%"的比例规则；物块与板的长度比不再恒定
   （板越长物块相对越小，属预期行为）。
4. 板长 L = 2 m（最小值）时物块（2.0 m）与板等宽，属允许的临界情形，
   物理判定（滑出、中心过缘）须保持自洽，不得出现除零/负区间错误。
5. 物块上的名称与速度文字沿用现有自适应规则（放不下时上移到块上方）。

## 二、正方向约定与默认初速度（需求 2.1）

1. **正方向：水平向右为正**，场景内须有明确的正方向标注。
2. **默认 A、B 均向右运动**：
   - `v₀A` 默认 12 m/s（向右，维持不变）；
   - `v₀B` 默认值由 0 改为 **+2.0 m/s**（向右）。
3. `v₀B` 滑条仍保留 −10 ～ +10 m/s 可调（负值向左），仅默认值变更。

## 三、运动区域与越界停止（需求 2.2）

1. 主演示画面定义**固定运动区域**（世界坐标）：
   - 左边界 `REGION_MIN = −10 m`，右边界 `REGION_MAX = 40 m`，总跨度 50 m；
   - 比例尺固定：`scale = 画布可用宽 / 50`，**不再动态缩放取景**
     （废除"镜头随运动拉远"方案，画面全程静止，赛道感固定）。
2. **越界停止**：任一物体（物块 A 或板块 B）在**未停止**的状态下完全越出
   运动区域（判定：A 的整体越过边界，即 `xA ≥ 40` 或 `xA + 2.0 ≤ −10`；
   板的整体越过边界，即 `xB ≥ 40` 或 `xB + L ≤ −10`）时，**整个演示立即结束**。
3. 越界结束时的状态提示须说明"（物块/板块）已超出运动区域，演示结束"。
4. 运动区域须可视化：左右边界以醒目竖线（虚线）标示，配合正方向标注。
5. 正常停下（共速后停、板上停、地面摩擦停）的情形不受影响，
   仍按原需求 5 的"停稳后延时 1 秒结束"执行。
6. 地面距离刻度覆盖整个运动区域（含负半轴）。

## 四、验收标准

1. 任意板长（2–10 m）与任意运动阶段下，物块 A 像素宽 = 像素高（正方形），
   尺寸恒为 2.0 m × scale，不随板长/运动变化。
2. 默认打开页面：v₀A = 12、v₀B = +2.0（均为向右），画面有正方向标注与运动区域边界线。
3. 默认参数运行：A 滑出板后继续向右，越过 +40 m 边界时演示立即结束，
   状态栏提示越界信息；v-t / s-t 图在越界时刻截断。
4. v₀B = −8 时板向左运动，板完全越出 −10 m 边界后演示立即结束。
5. 固定比例尺下：板 6 m 画为约 86 px（scale ≈ 14.3 px/m @880 画布），
   全程无缩放跳变。
6. 既有物理逻辑回归不受影响：双摩擦、共速锁死/slipAfter、滑出判定、
   摩擦生热、B 静止情形、数据面板语义均与 v2 一致。
