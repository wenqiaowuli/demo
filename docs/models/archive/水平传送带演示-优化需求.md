# 水平传送带演示网页 · 优化需求

## 1. 背景与目标
- **对标文件**：`horizontal-conveyor-belt.html`（水平传送带演示｜高中物理，仓库根目录）。
- **在线地址**：https://wenqiaowuli.github.io/demo/horizontal-conveyor-belt.html
- **参考**：`inclined-conveyor-belt.html`（斜面传送带，滚筒画法参考）、已优化的平抛/斜抛/上抛页（快捷键、charts-row、aria 惯例）。
- **目标**：不改动物理模型，先把传送带**画得像传送带**（核心：两端滚筒、环形带面、机架），再补传送带模型必考的教学读数与交互一致性。
- **已核对（保持不变）**：
  - 相对速度 `vRel = v − v带` → 动摩擦方向 = −sign(vRel) → 加速度方向随动，逻辑正确。
  - `step()` 分段积分处理"单步内跨共速点"，正确；共速后无摩擦匀速。
  - 三个情景（轻放 / 刹停 / 反向放上）物理口径正确。
  - 说明：当前代码 L391-399 其实画了两个半径 14px 的深色小圆，但无轮毂/辐条/旋转、且一半被带面遮挡，视觉上等同"没有轮子"——本次必须重画。

## 2. 关键决策
- **主画布改为专注画传送带**：物块+带+受力 + 机架；v-t 图移出主画布（见 FR6）。
- **g 保持可调滑条（5–15）**：默认值由 9.8 改为 10（与系列平抛/斜抛固定 g=10 对齐），参数卡注明"默认 10，可按需调节"。
- **运行中滑条禁用**（与平抛/斜抛一致），不再"可拖但无效"。
- **新增暂停/继续**（当前只有开始/重置），并配空格/R 快捷键（与系列一致）。

## 3. 功能需求

### FR1 两端滚筒重画（P0，核心）
- 滚筒半径加大到 **≈18px**，画在主带两端（替代现有 14px 暗圆）。
- 视觉：金属灰**径向渐变**填充 + 深色外缘描边 + **轮毂**（中心小圆）+ **4~6 根辐条**。
- **辐条随带速旋转**：旋转角 `angle = t · v带 · k`（k 为视觉系数，如 0.5~0.8，示意即可，非精确物理比例）；`v带=0` 时静止。
- 旋转方向与带向一致：带向右（v带>0）→ 滚筒顺时针；带向左 → 逆时针。

### FR2 环形带面（P0）
- 不再画一整块 110px 高矩形，改为**薄带闭环**（侧视结构）：
  - **上承载带面**：高 ≈18px 的水平带，两端在滚筒位置处断开（从 `滚筒圆心 x + R` 到 `滚筒圆心 x + beltW − R`），让滚筒圆缘在上方露出。
  - **回程带**：滚筒圆心下方一条高 ≈18px 的细带，同样两端断开，形成"上走带、绕滚筒、下回程"的闭环视觉。
- 上带面、回程带均带随带速移动的纹理（见 FR4）。
- 物块放在**上承载带面**之上。

### FR3 机架与地面（P0）
- 两端滚筒轴心处画机架：小横撑 + 两侧支腿 + 底部**地面线**。
- 机架颜色比带面更暗（如 `#1a2228` 系），不抢物块/受力箭头注意力。
- 地面线上可加"地面"字样或简单阴影。

### FR4 带面纹理（P0）
- 现在全高竖线（L384-389）像栅栏，改为**短斜纹 / 菱形防滑纹**：
  - 上承载带面、回程带各画一组随带速平移的纹理，间距 40px。
  - 偏移量 `(t · v带 · PIX_PER_M) % 40`（沿用现逻辑），v带 为负时方向自动反向。
- 纹理颜色低调（`rgba(120,160,200,0.25)` 量级），保证受力箭头清晰。

### FR5 相对滑动距离与摩擦生热（P1）
- **新增两个读数卡**：`相对滑动距离 s相对`、`摩擦生热 Q`。
- 物理：`s相对 = ∫|v − v带| dt`（在 `step()` 内累加 `|vRel|·dt`，仅未共速时）；`Q = μmg · s相对`（MASS=1，即 `μ·g·s相对`）。
- 共速后 s相对 停止增长、Q 不再增加；出界（离带）后 Q 定格。
- 显示位置：data-row 追加两个 data-card（摩擦生热用绿色 `accent`）。

### FR6 v-t 图拆出主画布并增强（P1）
- 将 v-t 图从主画布顶部（现 L518-571）**移出**，放到主画布**正下方独立面板**，宽屏铺满同宽、与平抛/斜抛 charts-row 风格一致（深色卡片 + 蓝色外框 `#3388dd`）。
- 主画布高度相应收窄（如 880×240），专注传送带。
- 图内增强：
  - 物块 v（橙）、带速 v带（青虚线）两条线（沿用）。
  - **两线间面积阴影**（半透明），图例注明"阴影面积 = 相对位移 s相对"。
  - **共速时刻标注**：当从 |vRel|>ε 变为共速时，画竖线并标"共速 t=…s"。
  - 横轴 t 最近 10s 滑动窗沿用；纵轴 ±7 m/s 沿用。

### FR7 轻放情景落下动画（P1）
- 仅在"轻放情景"（v0=0、v带>0）且**初始从静止启动**时触发：
  - 重置后物块先在上承载带面上方出现，用约 0.3s 下落到带面（带过渡动画）。
  - 落下期间物块尚未接触带面：**不积分、无摩擦、相对位移不累计**。
  - 触带瞬间开始正常物理积分。
- 实现方式：新增 `state.drop` 标志（轻放时置真），在 `loop()` 中先推进落下相位，落完再进入 `step()`。
- 其他情景（刹停 / 反向放上 / 手动调参）不触发，直接位于带面。

### FR8 滑出带端行为（P1）
- 现状：物块中心出带界即硬停"已出界"（L623-628）。
- 改为：物块滑出上承载带面后，**离开带面、失去摩擦、保持当前速度匀速滑出画布**。
  - 新状态 `offbelt`（或 `finished` 语义扩展）：`a=0, f=0`，HUD 显示"已离开传送带，无摩擦，做匀速直线运动"。
  - 按钮状态文本改为"已离带"；重置可恢复。
  - 物块滑出过程中给一个自由下落（抛物线）的视觉亦可，但**非必须**（先做匀速滑出）。

### FR9 运行中滑条禁用（P2）
- `running / offbelt` 期间禁用 `v0 / μ / g / v带` 四个滑条，加 `opacity:0.45`（沿用平抛样式）。
- 重置后恢复可用。

### FR10 暂停/继续 + 快捷键（P2）
- 新增「暂停」「继续」按钮（或开始按钮 toggle），逻辑与平抛/斜抛一致。
- **空格**：开始（idle）→ 暂停（running）→ 继续（paused）；**R**：重置。
- 焦点在 INPUT/BUTTON/SELECT/TEXTAREA 时不触发（复用斜抛 `togglePlay` 模式）。

### FR11 无障碍（P2）
- 主画布 canvas 加 `role="img"` + `aria-label`（如"水平传送带上物块运动演示"），HUD data-row 加 `aria-live="polite"`。
- 播放中 `aria-live` 置 `off`，暂停/结束/重置恢复 `polite`（与斜抛一致）。

### FR12 出界后 HUD 摩擦清零（P3）
- `updateHud()` 增加 `offbelt` 分支：`f=0、a=0`，避免出界后仍显示 f≠0。

### FR13 g 默认值与说明（P3）
- `g` 滑条默认值 `9.8 → 10`；参数卡内一行说明："重力加速度 g 可调（5–15），默认 10，与其他演示页一致"。

## 4. 风格 / 一致性
- 沿用现有深色主题（`#0d141b` 底、`#3388dd` 强调、卡片、DPR 适配、fitCanvas）。
- 新增 v-t 独立面板与平抛/斜抛 charts-row 视觉统一。
- 受力箭头配色沿用：物块 v 橙 `#ffaa44`、带速青 `#44ddff`、摩擦红 `#ff5577`、相对方向绿 `#aaff66`。

## 5. 非目标（本次不做）
- 空气阻力、物块质量可调（MASS 仍固定 1）。
- 皮带打滑/静摩擦-动摩擦切换的细化（共速即无摩擦，维持现状）。
- 真实物理比例的滚筒角速度（辐条转速为视觉示意）。
- 物块滑出后的自由落体轨迹（非必须，先匀速滑出）。

## 6. 验收标准
- [ ] 主画布两侧有**明显滚筒**：金属渐变 + 轮毂 + 辐条，辐条随带速旋转，v带=0 时静止。
- [ ] 传送带为**闭环**：上承载带面 + 回程带，两端包住滚筒；物块位于上带面之上。
- [ ] 有机架支腿与地面线，整体像一台传送带机器。
- [ ] 带面纹理为短斜纹/菱形且随带速平移，不再是全高栅栏线。
- [ ] 新增「相对滑动距离 s相对」与「摩擦生热 Q」读数，共速后停止增长、数值 = μ·g·s相对。
- [ ] v-t 图在主画布下方独立面板；含两线面积阴影（图例注明=相对位移）与共速时刻标注。
- [ ] 轻放情景：物块从带上方落下约 0.3s 后触带开始加速，落下期间无摩擦、s相对不累计。
- [ ] 物块滑出带端后 f=0、a=0、速度不变匀速滑出，HUD 文案正确，按钮显示"已离带"。
- [ ] 运行中四个滑条禁用变灰；重置恢复。
- [ ] 空格 toggle 开始/暂停/继续、R 重置，且不与输入/按钮焦点冲突。
- [ ] canvas 有 aria-label，HUD 播放中 aria-live=off、暂停/结束/重置=polite。
- [ ] g 默认 10 且有说明；滑出后 HUD 摩擦不为 0 的旧问题消失。
- [ ] 原物理行为（共速判定、三情景、v-t 曲线趋势）无回归。
