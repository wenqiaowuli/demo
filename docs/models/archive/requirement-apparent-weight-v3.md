# 需求：超重和失重演示网页 v3（画面内容修订，替代 v2）

> 在 v1（`requirement-apparent-weight-v1.md`）基础上修订主画布显示内容。**v2 的 5 条修订全部作废**，以本文件 3 条为准。未提及的部分（物理模型、行程脚本、参数、图表、按钮、快捷键、布局骨架）维持 v1 不变。

## 一、修订内容

### 1. 主画布：去掉所有速度显示
- 删除红色速度矢量 v，删除 "v = 0" 标注——主画布不再出现任何速度相关显示。
- 速度只在 v-t 图与实时数值面板中查看，画布不重复。
- 图例同步删除 "→ 速度 v" 一项。

### 2. 主画布：电梯左侧显示加速度的大小和方向
- 电梯**左侧**用一个带箭头的有向线段表示加速度：
  - **方向** = 箭头朝向（a > 0 竖直向上 / a < 0 竖直向下）；
  - **大小** = 线段长度（随 |a| 变化）。
- 同时标注数值，随阶段实时更新：
  - a > 0：`a = +2.0 m/s²`
  - a < 0：`a = -2.0 m/s²`
- **a = 0 时：有向线段消失（不画箭头）**，仅保留文字标注 `a = 0`（含待机、匀速、停靠阶段）。
- 图例保留 "→ 加速度 a"。

### 3. 主画布：电梯右侧气泡只保留一项
- 气泡只显示一行：**"视重 = 720 N"**（当前实时示数），数值与体重计读数（实时数值面板"视重 F"）完全相等。
- 删除 "实重 G = 600 N" 及 F/G 倍数对比等内容。
- 气泡颜色随状态变化不变（超重橙 `#ff9933` / 正常白 `#ffffff` / 失重蓝 `#66aaff` / 完全失重青 `#33ddcc`）。

### 4. 其他
- 实时数值面板标签维持 v1 的 "视重 F（体重计）" 不变。
- v2 中 "示重（体重计）" 改名、"视重（体重计）= xxx N" 气泡文案均作废。
