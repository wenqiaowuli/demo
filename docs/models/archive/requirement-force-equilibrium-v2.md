# 需求：共点力平衡演示 v2（初始竖直悬挂 + 目标夹角语义修订）

> 在 v1（`requirement-force-equilibrium-v1.md`）基础上修订交互模型。未提及的部分（视觉风格、布局、物理模型与公式、图表、颜色约定、按钮状态矩阵、v1 验收中未被本文件修订的条款）维持 v1 不变。

## 背景与目标
- 演示叙事对齐教学过程：**小球一开始默认竖直静止悬挂**，随后被水平向右**缓慢拉动**，最终**停在"目标夹角"设定的位置**（停下时绳与竖直方向的夹角 = 目标夹角）。
- 滑条语义从"当前夹角"修订为"目标夹角"（最终停留角）。

## 修订清单

### R1 初始状态：竖直静止悬挂
- 打开页面 / 重置（按钮或 R 键）/ 待机态调整参数滑条后：小球回到**竖直静止悬挂**（θ=0°），读数 F=0.00 N、T=G=mg，画布状态文字含"竖直悬挂：T = G"。
- 待机态即初始态；"目标夹角"滑条保持用户设定值（默认 45°），**不直接驱动小球**。

### R2 目标夹角 = 最终停留角
- 滑条"目标夹角 θ"只设定自动演示结束时小球停下的角度，调整它不移动小球。
- **自动演示 = 缓慢拉动过程**：θ 从 0° 匀速拉到目标角（默认 1× 时单程 8 s），小球沿弧缓慢向右上方移动；结束后小球**停在目标角**（ended 态保持该位置不回弹），按钮"▶ 再来一次"重新从竖直拉动。
- 运行/暂停中禁用 θ、m 滑条（维持 v1）；播放速度实时可调。

### R3 移除画布直接拖拽
- 删除 v1 的"待机时拖拽小球沿弧移动"交互（与目标角语义冲突：拖拽中途停下的角度并非目标角）；小球位置仅由拉动过程决定。
- 画布提示文字与图例中的拖拽说明同步移除，pointer 拖拽代码删除。

### R4 状态文字与读数
- 画布右上提示按状态切换：
  - idle / ended → "设定目标夹角后点击自动演示，小球将被缓慢拉起"（ended 附加"已停在目标夹角 θ=XX°"）；
  - running / paused → "缓慢拉动中：θ 连续增大，F 与 T 连续增长"。
- 左上常显"准静态平衡：ΣFx=0，ΣFy=0"（θ≈0° 时附加"竖直悬挂：T = G"）维持 v1。
- 实时数值面板 θ 显示**当前角度**：待机 0° / 运行中扫描值 / 结束后目标角；F、T、Tx、Ty、T/G 随当前角度实时更新。

### R5 参数变化的重置行为
- idle 或 ended 态调整目标角或质量滑条：小球立即回到初始竖直悬挂（θ=0°），等待下一次拉动（沿用系列 reset 约定）。

## 验收标准（修订，替代 v1 中对应条款；未列出的 v1 条款继续有效）
1. 打开页面 / 重置后：球竖直悬挂，θ 读数 0°、F=0.00 N、T=10.00 N（m=1）；目标滑条为 45° 但小球不动。
2. 自动演示（默认目标 45°）：球从竖直缓慢拉至 45°（约 8 s @1×）；过程中 F 从 0.00 连续增长至 10.00 N、T 从 10.00 至 14.14 N，两图游标同步前进；结束后球**停在 45°**，按钮变"▶ 再来一次"。
3. "▶ 再来一次"从竖直重新拉至目标角；"暂停/继续"在拉动中途冻结/恢复角度；运行中滑条禁用。
4. ended 态调整目标角（如改为 30°）：球立即回到竖直悬挂（θ 读数 0°）；再次自动演示后停在 30°（F=5.77 N、T=11.55 N）。
5. R 键 / 重置按钮：任意状态下球回竖直静止悬挂。
6. v1 中"重力箭头恒长 100 px、Tx≡F、Ty≡mg、T≥mg、T 箭头不越过 O、平行四边形角点在绳延长线上"等条款维持不变。
7. 画布与图例不再出现任何拖拽提示。
