## 六、双摩擦系数（本次新增）
关于动摩擦系数，分成两块：

1. **μ₁：物块 A 与板 B 之间的动摩擦因数**
   - 由现有"动摩擦 μ"滑条改造并更名（标签如"A-B 摩擦 μ₁"）。
   - 范围 **0.05–0.50**，步长 0.05，**默认 0.20**。
2. **μ₂：木板 B 与地面之间的动摩擦因数（新增滑条）**
   - 范围 **0–0.50**，步长 0.05，**默认 0**。
3. 运行中两滑条禁用；idle 时实时联动数据面板与画面。

### 物理逻辑（随 μ₂ 分情况，高中板块模型完整版）
- **滑动阶段**（A 在 B 上且相对滑动）：
  - A：`aA = μ₁g`（减速，不变）。
  - B：受 A 的滑动摩擦（向前 `μ₁m_A·g`）与地面摩擦（向后 `μ₂(m_A+m_B)·g`）：
    - 若 `μ₁m_A > μ₂(m_A+m_B)`：B 向前加速，`aB = [μ₁m_A − μ₂(m_A+m_B)]·g / m_B`；
    - 若 `μ₁m_A ≤ μ₂(m_A+m_B)`：**B 保持静止**（位移恒为 0），A 在静止板上滑动。
- **未滑出（S_rel 峰值 ≤ L）**：
  - 共速时刻、共速速度按上述加速度用运动学计算（μ₂>0 时动量不守恒，不得套用 `m_A·v₀A/(m_A+m_B)`）；
  - 共速后：**μ₂ = 0** → 一起匀速（保持现版本）；**μ₂ > 0** → 一起匀减速 `a = μ₂g` 直至停止。
  - μ₂ = 0 时退化为 `v共 = m_A·v₀A/(m_A+m_B)`（必不为零）。
- **滑出（S_rel 达到 L）**：
  - 滑出后 A 在地面：受地面摩擦 `μ₂m_A·g` 减速（μ₂ = 0 则匀速延续）；
  - B 失去 A 的摩擦力：受地面摩擦 `μ₂m_B·g` 减速（μ₂ = 0 则匀速延续）；
  - v-t 图两线不汇合；μ₂ > 0 时两条线各自线性下降到 0。
- **特殊情形**：B 静止且 A 在板上减速到 0（未滑出）→ 两者速度均为 0，v-t 图 A 线降至 0、B 线恒为 0。
- 滑出判定不变：`S_rel(t) > L`。

### 摩擦生热（总生热）
- 卡片改为显示 **总生热 = A-B 摩擦生热 + 地面摩擦生热**（标题注明"总"或构成）。
- Q₁（A-B）= `μ₁m_A·g × S_rel`（滑动阶段相对滑移）。
- Q₂（地面）= 地面摩擦力 × 对地滑移距离，分段计：A 压在 B 上时正压力 `(m_A+m_B)g`；滑出后 B 为 `m_B·g`、A 在地面为 `m_A·g`。

### 兼容性
- **μ₂ = 0（默认）时，所有行为与当前线上版本完全一致。**

## 七、v-t 图分情况逻辑
按第六节物理逻辑绘制：
1. **未滑出且 μ₂ = 0**：A 减速、B 加速，汇合于非零共速速度，之后共同水平直线。
2. **未滑出且 μ₂ > 0**：汇合后共同线性下降到 0。
3. **B 静止情形**（`μ₁m_A ≤ μ₂(m_A+m_B)`）：B 线恒为 0；A 线下降至 0（停于板上）或降至滑出时刻速度（随后在地面继续受 μ₂ 减速）。
4. **滑出**：两线在滑出时刻分离不汇合；μ₂ = 0 各自水平延续，μ₂ > 0 各自线性下降到 0。
5. 共速竖线（未滑出时）、滑出转折竖线（滑出时）按实际状态绘制。
