## 三、物理模型与约定
1. 矢量颜色约定（全页统一）：F₁ 黄 `#ffcc44`、F₂/F₁′ 青 `#33ddcc`、合力 F 红 `#ff5555`、辅助虚线 `rgba(255,255,255,0.4)`；图表曲线与对应矢量同色。
2. 矢量长度 ∪ 力大小：画布内线性比例，自适应使最长矢量不超过画布可用区域的 40%；左下角画比例尺线段并标注（如"5 N"）。
3. 角度约定：水平向右为 x 正方向、竖直向上为 y 正方向；角弧从 x 正方向（或 F₁ 方向）逆时针度量，标注度数。
4. 合成（平行四边形定则）：F⃗ = F⃗₁ + F⃗₂；大小 F = √(F₁² + F₂² + 2F₁F₂cosθ)；方向角 φ = atan2(F₂sinθ, F₁ + F₂cosθ)（相对 F₁）。
5. 合力范围：|F₁ − F₂| ≤ F ≤ F₁ + F₂；θ 越大（两分力大小固定）合力越小。
6. 分解（合成的逆运算）：分解结果**不唯一**，附加条件后才唯一——① 正交分解（沿 x/y 轴）② 已知两分力方向（平行四边形作图得唯一解）。
7. 按两已知方向分解的可行域：合力方向必须位于两分力方向线之间（且两方向线不共线），此时两分力沿各自方向的"效果"均为正；越界时数值面板显示 "—"，主画布显示提示条"合力不在两分力方向之间，无法按效果分解"。
8. 教学要点（fixed-note 必须呈现）：
   - 合力与分力是**等效替代**关系：合力与分力不能同时参与受力分析（高频易错点）；
   - 两分力大小固定时，夹角越大合力越小；范围 [F₁−F₂, F₁+F₂]；
   - 特殊情形：同向 θ=0° → F=F₁+F₂；反向 θ=180° → F=|F₁−F₂|；垂直 θ=90° → F=√(F₁²+F₂²)；等大且 θ=120° → F=F₁=F₂；
   - 分解不唯一：同一合力可有无穷多组分解，分力大小可以任意大；附加条件（如沿两指定方向）后唯一；
   - 正交分解是通用方法：Fx = Fcosα，Fy = Fsinα。

## 四、模式 A：力的合成

## 五、模式 B：力的分解
### 主画布
1. 合力 F（红色加粗矢量）从 O 出发，方向角 α 可调；以 F 为**对角线**作平行四边形（辅助虚线），两邻边即分力 F₁′（黄）、F₂′（青），带箭头与数值标注；α 角弧标注。
2. 三种分解方式（参数面板内分段控件三选一）：
   - **① 正交分解**：沿水平 / 竖直方向，Fx = Fcosα、Fy = Fsinα；方向线为坐标轴。
   - **② 按两已知方向**：两条虚线方向线（角度 φ₁、φ₂ 可调，方向线可拖拽），过 F 末端作两方向的平行线交出唯一解；可行域判定见第三节第 7 条，越界时画布提示条显示。
   - **③ 多解性观察**：固定 F 与分力 F₁′ 方向 φ₁，分力 F₂′ 方向 φ₂ 连续可调——每一步给出一组解 (F₁′, F₂′)，展示"同一合力有无穷多组分解"。
3. **拖拽交互**（idle / paused 态）：方式② 可拖拽两条方向线的角度；各矢量端点不可拖（合力由滑条控制）。

### 参数（按方式启停）
| 参数 | 范围 | 步长 | 默认值 | 说明 |
|------|------|------|--------|------|
| 合力 F 大小 | 2 ~ 14 N | 0.5 | 6 | 三种方式共用 |
| 合力方向角 α | −80° ~ 80° | 5° | 30° | 相对 x 正方向，可斜上/斜下 |
| 分解方式 | 正交 / 两方向 / 多解 | — | 正交 | 分段控件 |
| φ₁（F₁′ 方向角） | −80° ~ 80° | 5° | 0° | 仅方式②③启用 |
| φ₂（F₂′ 方向角） | −80° ~ 180° | 5° | 70° | 仅方式②启用；方式③为 10° ~ 170° |
| 播放速度 | 0.1 ~ 2× | 0.1 | 1 | 自动演示用，运行中实时可调 |

- 与当前方式无关的滑条置灰禁用；可行域越界（方式②φ₂ 覆盖 α 失败、方式③ φ₂ ≤ α）时数据面板对应项显示 "—"。

### 图表（双图）
- **左图：Fx–α / Fy–α 双曲线**（三方式共用）——Fx = Fcosα（橙）、Fy = Fsinα（蓝），横轴 α −80°~80°，当前点 + 气泡；体现正交分量随方向角的连续变化。
- **右图：多解曲线 F₁′–φ₂ / F₂′–φ₂**（方式③核心图；方式①②隐藏右图改为单图居中？**否**——方式①②时右图显示当前分解的分量条形对比：水平条形 F₁′、F₂′（或 Fx、Fy）+ 合力 F 参考线，静态数值图）。
  - 方式③曲线：横轴 φ₂ ∈ (α, 179°]，F₁′ = F·sin(φ₂−α)/sin(φ₂−φ₁)（黄）、F₂′ = F·sin(α−φ₁)/sin(φ₂−φ₁)（青）；φ₂→α⁺ 时 F₁′→0、F₂′→F；φ₂→180°− 时两分力发散至无穷（超出量程截断）；F₂′ 在 φ₂−φ₁=90° 处取极小值；当前 φ₂ 游标 + 当前点。

## 十、物理公式（实现参考，勿改动）
- 合成：F = √(F₁² + F₂² + 2F₁F₂cosθ)；φ = atan2(F₂sinθ, F₁ + F₂cosθ)
- 正交分量（合成）：Fx = F₁ + F₂cosθ；Fy = F₂sinθ
- 正交分解：Fx = F·cosα；Fy = F·sinα
- 按两方向分解（u₁、u₂ 为两方向单位矢量，F⃗ = a·u₁ + b·u₂）：
  - F₁′ = F·sin(φ₂ − α) / sin(φ₂ − φ₁)；F₂′ = F·sin(α − φ₁) / sin(φ₂ − φ₁)
  - 可行条件：φ₁ < α < φ₂（角度序不交叉）且两方向线夹角 < 180°
- 合力范围：|F₁ − F₂| ≤ F ≤ F₁ + F₂
