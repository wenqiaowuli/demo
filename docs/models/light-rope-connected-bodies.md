# 轻绳连接体动画网页

## 1. 模型卡与教材对应

- **清单编号**：必修第一册 #24（拓展应用）
- **页面 slug**：`light-rope-connected-bodies`
- **文件名**：`light-rope-connected-bodies.html`
- **所属内容**：必修第一册第四章“运动和力的关系”——牛顿运动定律的应用
- **查重结论**：远程 `origin/main` 当前没有水平光滑面上两个物块由轻绳连接、外力作用于其中一个物块的演示。已有的 `spring-vs-rope-demo.html` 演示剪断弹簧/绳后的运动，不是本模型；`block-plate.html` 是接触摩擦耦合，也不是本模型。
- **页面范围**：水平光滑面上，B 在左、A 在右，两个物块由绷紧轻绳连接；恒力向右作用于右侧物块 A，两物块从静止开始共同向右运动。
- **非目标**：不加入滑轮、摩擦、弹簧、绳质量、绳伸长、绳松弛或碰撞，避免混入其他模型。

## 2. 冻结的物理规格

- 物块质量分别为 `mA`、`mB`，水平面光滑；轻绳质量忽略、不可伸长，且始终绷紧。
- 外力 `F` 水平向右作用于 A。两物块受绳长约束，具有相同的速度和加速度。
- 对 A+B 系统：`F = (mA + mB) a`，所以 `a = F / (mA + mB)`。
- 对 B：`T = mB a`，所以 `T = mB F / (mA + mB)`。
- 对 A：`F - T = mA a`。实时计算值须同时满足系统方程和两个隔离方程。
- 竖直方向：支持力分别平衡重力，`NA=mA g`、`NB=mB g`；页面不重点演示竖直方向。
- 从静止开始且 F 恒定：`vA(t)=vB(t)=a t`；两物块从各自初位置算起的位移相同 `sA(t)=sB(t)=½ a t²`；坐标位置为 `xA=xA0+½at²`、`xB=xB0+½at²`，间距 `xA-xB` 恒定。
- 边界：`F=0` 时 `a=0`、`T=0`，物块保持静止；两质量均须大于零。

## 3. 页面需求与交互

- 延续系列浅色主题与单列页面布局，内容最大宽约 880px，Canvas 按 DPR 和容器宽度自适应。
- 主画布：地面、左侧 B/右侧 A 两物块、绷紧轻绳、外力 F 与两端绳张力 T 的矢量；采用镜头跟随和滚动刻度，避免物块到边缘时被误认为碰撞。
- 参数：`mA`、`mB`、`F`；显示单位、当前值和默认值。质量范围须为正值；播放中禁用参数，暂停/结束后调参则从 t=0 重算。
- 播放：开始、暂停/继续、单步、重置、播放速度和时间进度控制。总仿真时长固定，结束时明确显示“演示结束”，不添加虚构墙面或碰撞。
- 实时数据：时间、加速度、A/B 速度、A/B 位移、两物块间距、绳张力；A/B 速度和位移应一致，位置差保持初始间距。
- 图表：`v-t` 显示 A/B 重合的共同速度；`x-t` 显示两条同形抛物线，同一时刻的纵坐标差恒等于初始绳长。F=0 时两曲线为水平线。
- 受力分析：右侧 A 显示 F 向右、T 向左，并显示重力和支持力；左侧 B 显示 T 向右，并显示重力和支持力。提供“整体/隔离 A/隔离 B”受力视图切换。若场景主画面隐藏竖直力，标注“主场景仅显示水平方向力”。
- 箭头长度按力大小比例绘制，标签数值同步显示；力接近时使用错层布置避免箭头重叠。F=T=0 时不绘制水平力箭头。
- 公式区同步显示整体法和隔离法，并指出系统分析时轻绳张力为内力、在整体合力中抵消。
- 窄屏下图表纵向排列，控制区可换行；所有滑条和按钮带可访问名称。

## 4. 验收矩阵

| 用例 | 参数/操作 | 预期结果 |
|---|---|---|
| 默认值 | `mA=2 kg, mB=3 kg, F=10 N` | `a=2 m/s², T=6 N`；A/B 加速度与速度相同 |
| 常规场景 | `mA=2 kg, mB=1 kg, F=3 N` | `a=1 m/s², T=1 N`；受力方向和隔离方程正确 |
| A 质量变化 | 固定 `mB,F` 增大 `mA` | 系统加速度减小；张力 `T=mB F/(mA+mB)` 减小 |
| B 质量变化 | 固定 `mA,F` 增大 `mB` | 系统加速度减小；张力增大并小于 F |
| 零外力 | `F=0` | `a=0,T=0`，物块保持静止；水平力箭头消失，v-t 为零线，x-t 为两条水平线 |
| 极端质量比 | `mA=0.1 kg, mB=10 kg, F=10.1 N` | `a=1 m/s²,T=10 N`；F 与 T 接近，矢量和数值仍可辨认 |
| 隔离 A 校验 | 任意合法参数 | `F-T=mA a` |
| 隔离 B 校验 | 任意合法参数 | `T=mB a` |
| 整体校验 | 任意合法参数 | `F=(mA+mB)a` |
| 位移/速度约束 | 播放任意时刻 | `vA=vB`、`sA=sB`；`xA-xB` 恒为初始间距；绳长不变 |
| 播放中锁参 | 播放时尝试修改参数 | 参数控件禁用，不允许热插入物理参数 |
| 改参后重算 | 暂停后修改 F，再开始 | 回到 t=0、清空历史轨迹，并按新 F 重算 |
| 参数边界 | 质量滑条最小/最大值、F=0/最大值 | 无 NaN/Infinity，无物块重叠或矢量标签裁切 |
| 响应式 | 桌面、800px、390px 左右视口 | 无水平溢出，主画布、受力图和控件可读可操作 |
