## 2. 物理模型与教学背景

### 2.1 教学痛点与背景
“斜面上物块的运动”是高中物理必修一（牛顿运动定律与受力分析）与必修二（功与能）的核心枢纽模型。学生在学习时普遍存在以下认知难点：
1. **力的正交分解**：分不清 $mg\sin\theta$ 与 $mg\cos\theta$ 的几何来源与物理作用；
2. **静摩擦力大小与方向的不确定性**：难以掌握最大静摩擦力临界条件（$\tan\theta \le \mu_s$ 保持自锁静止）；
3. **上滑与下滑不对称性**：上滑阶段摩擦力向下（$a_{\text{up}} = g\sin\theta + \mu_k g\cos\theta$），下滑阶段摩擦力向上（$a_{\text{down}} = g\sin\theta - \mu_k g\cos\theta$），导致加速度不同、上滑与下滑时间不同；
4. **最高点判定盲区**：上滑至速度为零时，若 $\tan\theta \le \mu_s$，物块将**保持静止于最高点**而不会反向下滑。

### 2.2 产品目标
打造一个免安装、高性能、交互流畅的 Web 端高中物理仿真课件，实现：
1. **参数一键切换与平滑调节**：直观观察斜面倾角 $\theta$、动/静摩擦因数 $\mu_k/\mu_s$、初速度 $v_0$、物块质量 $m$ 对运动全过程的影响；
2. **矢量动态可视化**：实时绘制重力、支持力、摩擦力及正交分解矢量，并随运动状态即时变向变长；
3. **多运动图象联动**：提供仿真动画与 $v-t$（速度-时间）图、$s-t$（位移-时间）图及能量条形图的同频同步演示；
4. **高中教学专用场景预设**：一键加载“光滑斜面自由下滑”、“斜面自锁与临界滑动”、“上滑至最高点静止”、“上滑后反向下滑”、“初速度向下匀加速/减速/匀速”等典型教学题型。

### 2.3 边界与非目标
- **V1.1 范围**：单体刚性物块在固定刚性斜面上的平动模型，考虑重力、支持力、滑动摩擦力和静摩擦力。
- **非目标**：暂不包含斜面体自身的加速度（斜面相对地面滑动）、物块滚动/翻倒力矩分析、空气阻力、多物体连接体（如定滑轮/动滑轮/轻绳系统）以及弹簧振子碰撞等复杂体系。

## 3. 核心功能场景设计

系统预设 5 种高中物理典型场景，并支持用户完全自定义参数：

### 3.1 场景一：光滑斜面下滑（理想无摩擦模型）
- **物理机制**：$\mu = 0$。
- **受力特征**：受重力 $G=mg$ 与支持力 $N=mg\cos\theta$，$F_{\text{合}} = mg\sin\theta$。
- **运动规律**：初速度为 0 时做初速为零的匀加速直线运动，$a = g\sin\theta$。
- **教学核心**：探究加速度与倾角 $\theta$ 的正弦关系（验证 $a \propto \sin\theta$），讲解机械能守恒。

### 3.2 场景二：粗糙斜面静态自锁与临界滑动
- **物理机制**：物块由静止释放（$v_0=0$），比较下滑分力 $mg\sin\theta$ 与最大静摩擦力 $f_{\text{max}} = \mu_s mg\cos\theta$。
- **状态判定**：
  - 若 $\tan\theta \le \mu_s$：物块**静止自锁**，静摩擦力 $f = mg\sin\theta$（方向沿斜面向上），$a=0$；
  - 若 $\tan\theta > \mu_s$：物块**打破平衡加速下滑**，滑动摩擦力 $f_k = \mu_k mg\cos\theta$，$a = g(\sin\theta - \mu_k\cos\theta)$。
- **教学核心**：临界角概念 $\theta_{\text{crit}} = \arctan(\mu_s)$ 的动态验证。

### 3.3 场景三：粗糙斜面上滑至停（停于最高点自锁）
- **物理机制**：从斜面底端赋予沿斜面向上的初速度 $v_0 > 0$，且满足 $\tan\theta \le \mu_s$。
- **运动过程**：
  - **上滑阶段**：合力 $F_{\text{合}} = mg\sin\theta + \mu_k mg\cos\theta$，做匀减速运动，$a_{\text{up}} = g(\sin\theta + \mu_k\cos\theta)$（方向沿斜面向下）；
  - **到达最高点**：速度减为 0，用时 $t_{\text{stop}} = \frac{v_0}{a_{\text{up}}}$，上滑最大距离 $s_{\text{max}} = \frac{v_0^2}{2a_{\text{up}}}$；
  - **终态**：由于 $\tan\theta \le \mu_s$，物块停在最高点保持静止，不再下滑。

### 3.4 场景四：粗糙斜面上滑后反向下滑（完整上滑-下滑周期）
- **物理机制**：从斜面底端赋予沿斜面向上的初速度 $v_0 > 0$，且满足 $\tan\theta > \mu_s$。
- **运动过程**：
  - **阶段一（上滑）**：$a_{\text{up}} = g(\sin\theta + \mu_k\cos\theta)$，沿斜面减速至 0；
  - **拐点时刻（$t = t_{\text{turn}}$）**：瞬时速度为 0，摩擦力突变（由沿斜面向下突变为沿斜面向上）；
  - **阶段二（下滑）**：$a_{\text{down}} = g(\sin\theta - \mu_k\cos\theta) < a_{\text{up}}$，沿斜面加速回到出发点；
- **教学核心**：对比 $a_{\text{up}} > a_{\text{down}}$，观察 $v-t$ 图呈现斜率不对称的“折线”形态，上滑时间 $t_{\text{up}} <$ 下滑时间 $t_{\text{down}}$。

### 3.5 场景五：初速度沿斜面向下（匀加速 / 匀速 / 匀减速）
- **物理机制**：物块从斜面上端以初速度 $v_0$ 沿斜面向下运动。
- **状态判定**：
  - 当 $\sin\theta > \mu_k\cos\theta$（即 $\tan\theta > \mu_k$）：向下匀加速，$a = g(\sin\theta - \mu_k\cos\theta)$；
  - 当 $\sin\theta = \mu_k\cos\theta$（即 $\tan\theta = \mu_k$）：向下匀速直线运动，$a = 0$；
  - 当 $\sin\theta < \mu_k\cos\theta$（即 $\tan\theta < \mu_k$）：向下匀减速运动直至静止，$a = g(\mu_k\cos\theta - \sin\theta)$（方向沿斜面向上）。

## 6. 物理计算引擎与仿真规则

### 6.1 坐标系定义
- **一维沿斜面坐标轴**：以斜面底端为原点 $s=0$，沿斜面**向上为正方向**（$s \in [0, L]$）。
- **位移**：$s(t)$（$\text{m}$）。
- **速度**：$v(t) = \frac{\mathrm{d}s}{\mathrm{d}t}$，若 $v(t) > 0$ 表示沿斜面向上，$v(t) < 0$ 表示沿斜面向下。
- **加速度**：$a(t) = \frac{\mathrm{d}v}{\mathrm{d}t}$，正负表示沿正方向的投影。

### 6.2 动力学微分方程与阶段状态机

```
                      +-------------------+
                      |   物块处于静止    |
                      |   (v = 0)         |
                      +---------+---------+
                                |
             +------------------+------------------+
             |                                     |
  [初速度 v0 > 0 或 外部推动]           [初速度 v0 < 0 或 tanθ > μs]
             |                                     |
             v                                     v
   +-------------------+                 +-------------------+
   |   沿斜面上滑阶段   |                 |   沿斜面下滑阶段   |
   |   v > 0           |                 |   v < 0           |
   | a = -g(sinθ+μkcosθ|                 | a = -g(sinθ-μkcosθ|
   +---------+---------+                 +---------+---------+
             |                                     |
    [速度减至 v = 0]                         [到达底端边界 s <= 0]
             |                                     |
             v                                     v
   +-------------------+                 +-------------------+
   |  最高点判别逻辑   |                 |   运动停止 (碰底) |
   +---------+---------+                 +-------------------+
             |
     +-------+-------+
     |               |
 [tanθ <= μs]    [tanθ > μs]
     |               |
     v               v
(保持静止自锁)  (反向进入下滑阶段)
```

1. **上滑阶段（$v > 0$）**：
   $$N = mg\cos\theta$$
   $$f = -\mu_k mg\cos\theta \quad (\text{方向沿斜面向下})$$
   $$F_{\text{合}} = -mg\sin\theta - \mu_k mg\cos\theta$$
   $$a_{\text{up}} = -g(\sin\theta + \mu_k\cos\theta)$$
   最高点时刻：$t_{\text{top}} = \frac{v_0}{|a_{\text{up}}|}$，最高点位移：$s_{\text{top}} = s_0 + \frac{v_0^2}{2|a_{\text{up}}|}$。

2. **静止自锁判断（$v = 0$）**：
   - 当速度为 0 时：
     - 若 $\tan\theta \le \mu_s$：合力 $F_{\text{合}} = 0$，$a=0$，$f = mg\sin\theta$（静摩擦力阻碍下滑），物块永久保持静止。
     - 若 $\tan\theta > \mu_s$：静摩擦力不足以抵抗重力分力，物块立即转入**下滑阶段**。

3. **下滑阶段（$v < 0$）**：
   $$N = mg\cos\theta$$
   $$f = +\mu_k mg\cos\theta \quad (\text{方向沿斜面向上})$$
   $$F_{\text{合}} = -mg\sin\theta + \mu_k mg\cos\theta$$
   $$a_{\text{down}} = -g(\sin\theta - \mu_k\cos\theta)$$
   *(注：若正方向取向上，向下加速时 $a_{\text{down}}$ 值为负，大小为 $g(\sin\theta - \mu_k\cos\theta)$)*。

4. **边界碰撞处理**：
    - 若 $s(t) \le 0$（到达斜面底端），运动立即终止，位置锁定为 $s=0$，$v=0$；
    - 若 $s(t) \ge L$（冲出斜面顶端），运动终止并提示“物块冲出斜面顶端”，位置锁定为 $s=L$，$v=0$；
    - 两端均采用完全非弹性制停模型（恢复系数为 0）。撞击前动能记入边界耗散 $W_b$，不计入滑动摩擦生热 $W_f$；终止态边界约束力负责平衡沿斜面方向的剩余合力。

## 7. 实时数据与图表模块

### 7.1 实时数据面板卡片
- **运动阶段**：徽章显示（`静止自锁` / `上滑匀减速` / `瞬时静止最高点` / `反向匀加速下滑` / `到达底端`）
- **时间与位置**：当前时刻 $t$（$\text{s}$）、当前位置 $s$（$\text{m}$）、当前高度 $h = s\sin\theta$（$\text{m}$）
- **运动学量**：实时速度 $v$（$\text{m/s}$）、实时加速度 $a$（$\text{m/s}^2$）
- **动力学量**：重力 $G=mg$、垂直分力 $mg\cos\theta$、下滑分力 $mg\sin\theta$、支持力 $N$、实时摩擦力 $f$、合外力 $F_{\text{合}}$；到达端点后的边界约束力 $R$
- **能量统计**：
  - 动能：$E_k = \frac{1}{2}mv^2$
  - 重力势能（以底端为零势能面）：$E_p = mgh = mg s\sin\theta$
  - 机械能：$E = E_k + E_p$
  - 克服摩擦力做功累积（内能增量）：$W_f = \int f_{\text{滑}} \, \mathrm{d}s$
  - 端点制停耗散：$W_b=\sum \frac12 m v_{\text{撞击}}^2$（每次端点制停只计一次）
  - 能量账目：$E_0=E_k+E_p+W_f+W_b$；未发生端点碰撞时 $W_b=0$。数据面板分别显示 $W_f$ 与 $W_b$，端点碰撞损失不计入摩擦生热。

### 7.2 动态同步图表区（Canvas 渲染）
提供图表分析行（V1.2 起取消能量柱状图，仅保留两图，两列并排、窄屏单列）：
1. **$v-t$ 图（速度-时间图）**：直观展示上滑和下滑不同斜率的折线，实时光标随时间推进同步标注点；
2. **$s-t$ 图（位移-时间图）**：展示抛物线形态及最高点顶点。

能量量值（$E_k, E_p, E, W_f, W_b$）仅在实时数据面板以数字呈现，并以 $E_0=E_k+E_p+W_f+W_b$ 文字校验能量账目。

## 8. 交互与控制逻辑

1. **参数修改响应**：
   - 处于“播放中”或“暂停回放”状态时修改参数或切换预设场景，系统自动暂停并保留当前演示画面、标记参数待生效，并弹出半透明悬浮提示：“参数已调整，点击重置或重新播放生效”；
   - 点击重置以新参数从初始状态开始；点击播放以新参数从头重新播放。处于待播放状态修改参数时则立即重算和更新画布。
   - 处于“停止/重置”状态时修改参数，画布实时联动响应（例如拖动倾角 $\theta$ 时，斜面角度平滑旋转，受力矢量随之改变长度）。
2. **播放轴控制**：
   - **播放/暂停**：支持快捷键（`Space` 空格键）；
   - **单步步进（Step）**：通常前进 $\Delta t = 0.02\text{s}$；若下一物理事件（尤其最高点 $v=0$）落在本步区间内，则该步精确对齐事件时刻，使教师可观察瞬时状态；
   - **时间进度条**：支持自由拖拽回到历史时刻（回放分析）；播放结束后拖回历史时刻再播放，应从所选时刻继续，而非重置到起点。
3. **画布直观拖拽**：
   - 鼠标悬停在物块上变为抓手图标，允许沿斜面方向拖动物块直接改变初始位置 $s_0$。

### 9.1 物理正确性测试矩阵（必过项）

| 测试编号 | 测试场景 | 输入参数 | 预期输出与物理判据 |
| :--- | :--- | :--- | :--- |
| **TC-01** | 光滑斜面自由下滑 | $\theta=30^\circ, \mu=0, v_0=0, g=9.8$ | $a = 4.90\,\text{m/s}^2$；机械能 $E$ 全程恒定误差 $< 0.01\%$ |
| **TC-02** | 粗糙斜面静态自锁 | $\theta=30^\circ, \mu_s=0.60, v_0=0$ | 由于 $\tan 30^\circ \approx 0.577 \le 0.60$，物块不动，$a=0$，$f = mg\sin 30^\circ$ |
| **TC-03** | 粗糙斜面滑动临界 | $\theta=45^\circ, \mu_s=0.50, \mu_k=0.50$ | 由于 $\tan 45^\circ = 1.0 > 0.50$，物块下滑，$a = 9.8\times(\frac{\sqrt{2}}{2} - 0.5\times\frac{\sqrt{2}}{2}) \approx 3.46\,\text{m/s}^2$ |
| **TC-04** | 上滑最高点自锁 | $\theta=30^\circ, \mu_s=0.60, \mu_k=0.20, v_0=5$ | 上滑 $a_{\text{up}} = 9.8(0.5 + 0.2\times\frac{\sqrt{3}}{2}) \approx 6.598\,\text{m/s}^2$；$v$ 归零后**保持静止于最高点**，不发生下滑 |
| **TC-05** | 上滑后反向下滑 | $\theta=45^\circ, \mu_s=0.20, \mu_k=0.20, v_0=4$ | 上滑 $a_{\text{up}} \approx 8.32\,\text{m/s}^2$，下滑 $a_{\text{down}} \approx 5.54\,\text{m/s}^2$；上滑耗时 $t_1 <$ 下滑耗时 $t_2$ |
| **TC-06** | 质量无关性验证 | 保持 $\theta=30^\circ, \mu=0.2$，改变 $m$ 从 $1\text{kg}$ 至 $10\text{kg}$ | 运动加速度 $a$ 完全一致，仅受力数值按比例放大 |
| **TC-07** | 静摩擦临界角等号与邻域 | $\mu_s=0.50, \mu_k=0.20, v_0=0$；$\theta_c=\arctan(0.50)\approx26.565^\circ$，分别测试 $\theta_c$、$\theta_c-0.01^\circ$、$\theta_c+0.01^\circ$ | 等号与临界角下方保持静止自锁；临界角上方开始下滑，且 $a=g(\sin\theta-\mu_k\cos\theta)$。三个用例不得因浮点误差改变判定 |
| **TC-08** | 两端碰撞的能量闭合 | 分别构造撞到底端和冲出顶端的运动；覆盖非零滑动距离与非零撞击速度 | 每个终止态满足 $|E_0-(E_k+E_p+W_f+W_b)|/\max(1,E_0)\le 10^{-8}$；单次端点碰撞只累计一次 $W_b$，且碰撞动能不计入 $W_f$ |

## 11. 实现后审订补充（2026-10-09）

根据演示网页实现后的物理与交互审订，补充以下明确要求：
1. 斜面端点采用完全非弹性制停边界模型；撞击前动能归入边界耗散 $W_b$，与滑动摩擦生热 $W_f$ 分开统计，满足 $E_0=E_k+E_p+W_f+W_b$。
