## 3. 物理模型（v1.2 教材化）

水平地面上的物块受水平拉力 **F = k·t**，g = 10 m/s² 固定：

- 滑动摩擦力：f<sub>滑</sub> = μmg（μ 为动摩擦因数，教材正式定义）
- 最大静摩擦力：f<sub>max</sub> = f<sub>滑</sub> × (1 + s%)，s 为"最大静摩擦超出比例"（教材表述"最大静摩擦力略大于滑动摩擦力"）

| 阶段 | 条件 | 摩擦力 | 运动 |
|---|---|---|---|
| ① 静止 | F < f<sub>max</sub> | 静摩擦 f = F（随拉力同步增大） | v = 0，a = 0 |
| ② 临界 | F = f<sub>max</sub> | 最大静摩擦力 | 即将滑动，画面高亮"发生突变！" |
| ③ 滑动 | F > f<sub>滑</sub> | 突降为 f<sub>滑</sub>（恒定） | a = (F − f<sub>滑</sub>)/m，随 F 增大而增大 |

- 临界时刻 t* = f<sub>max</sub>/k；起动瞬间加速度跳变 a(t*) = Δf/m，Δf = f<sub>max</sub> − f<sub>滑</sub>
- 物块向右滑出 +20 m 边界即结束（对 x(t) 二分求根）
- 闭式解（t ≥ t*）：v = k(t² − t*²)/(2m) − f<sub>滑</sub>(t − t*)/m；x = k(t³/3 − t*²t + 2t*³/3)/(2m) − f<sub>滑</sub>(t − t*)²/(2m)

## 7. 推导与判断（v1.2：随参数实时更新，参照追及相遇页）

固定文案改为四行动态推导，数值随滑条联动：

1. 受力行：滑动摩擦力 f<sub>滑</sub> = μmg = 实时值；最大静摩擦力 f<sub>max</sub> = 实时值（超出 s%）
2. 临界行：t<sup>*</sup> = f<sub>max</sub>/k = 实时值
3. 突变行：Δf = 实时值，加速度跳变 Δf/m = 实时值
4. 判断行：F < f<sub>max</sub> 时物块静止（f = F）；F > f<sub>max</sub> 后 a = (F − f<sub>滑</sub>)/m 随拉力增大，物块加速滑离
5. 末行近似说明：粗略计算时可认为最大静摩擦力 ≈ 滑动摩擦力（超出比例调到 0% 即此情形）

- 地面线（2/3 高度）+ 接触面短斜线 + 米刻度（0–20 m）+ 右边界虚线
