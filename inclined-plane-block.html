使用说明

  • 播放控制：「▶ 播放 / ⏸ 暂停」或按空格键；「⏭ 单步」每次前进 0.02s，可捕捉最高点瞬时状态；拖动进度条可回放到任意历史时刻。
  • 速率：0.25×～4× 五档倍速，配合单步适合课堂讲解。
  • 拖拽物块：未播放时，鼠标悬停物块变为抓手，沿斜面拖动可直接设置初始位置 s₀。
  • 参数联动：播放中修改参数会自动暂停并提示，点击「重置」或「播放」后以新参数生效；未播放时修改参数画布实时联动。
  • 摩擦因数约束：恒保证 μk ≤ μs，若输入 μs < μk 会自动修正并提示。
  • 自锁判据：tanθ ≤ μs 时物块静止自锁（静摩擦 f = mg·sinθ）；上滑到最高点 v=0 后同样按此判据决定是否反向下滑。
  • 边界：物块到达底端（s=0）即停止；冲出顶端（s=L）时提示并锁定在顶端。
  • 能量账目：E₀ = Ek + Ep + Wf + Wb。Wf 为滑动摩擦生热；Wb 为物块撞到斜面端点后被制停所耗散的动能。能量量值见「实时数据」面板。
  • 图表区：v-t / s-t 图虚线为全程理论曲线、实线为已播放部分，光标点随动画同步。
